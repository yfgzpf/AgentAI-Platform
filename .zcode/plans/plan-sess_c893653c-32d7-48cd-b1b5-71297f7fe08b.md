### 新发现问题的根因（已调研确认）

**问题 X1：AI 计划不进入右侧任务列表**
- 主因：`ChatView.tsx:1167` 和 `:1331` **双重 `startTask` 调用** —— 工具结果触发一次、SSE `plan_created` 又触发一次；第二次把第一次的 activeTask 标记为 failed 并重置，面板闪烁/重置后易丢失。
- 次因：状态映射不全（`in_progress` 被当成 `pending`，`ChatView.tsx:1165`）；`plan:stage` 事件缺 stages 数组、`stage` key 可能为空串。

**问题 X2：子智能体任务不显示**
- 根因：**传输协议错配** —— gateway 只发 SSE（`subagent_start/done/error/progress`），GUI 却在用 **Socket.io** `sock.on('subagent:start')` 监听（ChatView.tsx:734-772），这些 handler **永远不会触发**。
- `api.ts:287-289` 只解析 3 个 SSE 事件，且**没有 `subagent_progress`**；`onSubagentStart/Done/Error` 声明了但从未接入 `setSubagents`。

**问题 X3：生视频/分镜失败 + "队列满"**
- 真实"队列满"来源：Agnes 免费 key（`AGENTAI_API_KEY`）429/503，错误分类器把它显示为"服务队列已满"。日志里大量 `免费用户 API 速率限制`。
- `tools.ts:1596-1603` 的 `generate_video` handler **仍用旧的盲目拼 Data URI 逻辑**，4fa471f 修复只覆盖了 `video.ts`，工具路径分镜→视频会复现 400。
- `/storyboard` 只对 503 重试，**429 直接失败**（video.ts:835-845）。
