# AgentAI Platform 计费模式重设计方案

## 📋 问题诊断

### 原有方案的问题

| 问题 | 描述 | 风险等级 |
|------|------|----------|
| **包月订阅不合理** | 用户包月后无限使用，我们无法控制实际消费 | 🔴 致命 |
| **自建充值系统不可行** | 我们无法管理用户的资金，资金在聚合平台 | 🔴 致密 |
| **页面强制锁定** | 生图/生视频完全锁定，用户体验差 | 🟡 中等 |
| **密钥缓存机制** | 需要验证是否正常工作 | 🟢 低 |

### 核心矛盾

```
┌─────────────────────────────────────────────────────────────┐
│                    资金流向分析                              │
│                                                             │
│  用户 → [聚合平台] → API Provider (OpenAI/Anthropic/...)   │
│         ↑                                                    │
│    资金在这里！                                              │
│                                                             │
│  我们 (AgentAI) 只是转发请求，无法控制扣费                    │
└─────────────────────────────────────────────────────────────┘
```

**结论**：我们不是资金管理者，而是**服务提供者**。

---

## ✅ 新方案：**"密钥制 + 功能引导" 模式**

### 设计理念

```
┌─────────────────────────────────────────────────────────────┐
│                      新商业模式                              │
│                                                             │
│  1. 用户向作者购买密钥（微信: agentai-platform）             │
│  2. 密钥 = 访问权限凭证                                     │
│  3. 聚合平台负责计费和余额管理                               │
│  4. 我们提供更好的 UI/UX 和功能增强                          │
│                                                             │
│  💰 利润来源：                                               │
│     - 密钥销售（一次性或周期性）                             │
│     - 私域引流（微信生态）                                   │
│     - 技术服务费                                             │
└─────────────────────────────────────────────────────────────┘
```

### 核心原则

1. **零资金风险** — 不碰用户的钱，不会亏钱
2. **简单可靠** — 不需要复杂的充值/扣费系统
3. **用户透明** — 看到的是聚合平台的真实价格
4. **私域引流** — 引导加微信获取密钥

## 🔧 技术实现

### 1. Store 重构 (`subscriptionStore.ts`)

```typescript
// 新的账户状态接口
interface AccountState {
  isActivated: boolean;      // 是否已激活（有有效密钥）
  activatedAt: number;       // 激活时间
  keySource?: 'factory' | 'custom';  // 密钥来源
}

// 主要方法
- activateWithKey(source)    // 激活账户
- deactivate()               // 停用账户
- isModelAccessible(modelId) // 检查模型是否可访问
- getActivationStatus()      // 获取状态描述
```

**关键变化**：
- ❌ 移除：`balance`, `totalSpent`, `recharge()`, `deductCost()`
- ✅ 新增：`isActivated`, `activateWithKey()`, `isModelAccessible()`

### 2. 页面访问控制 (`App.tsx`)

**旧逻辑**：`SubscriptionGuard` — 完全拦截未订阅用户
**新逻辑**：`FeatureGuide` — 允许进入但显示提示

```typescript
const FeatureGuide = ({ page, children }) => {
  const { isActivated } = useSubscriptionStore();
  
  if (isActivated || !page.requireSubscription) {
    return <>{children}</>;  // 直接显示
  }
  
  // 未激活：显示内容 + 顶部提示条
  return (
    <div>
      <div className="tip-bar">
        💡 当前使用免费内置模型，能力有限。
        <Button>添加密钥解锁高级模型</Button>
      </div>
      <div>{children}</div>  {/* 页面内容正常显示 */}
    </div>
  );
};
```

### 3. 状态栏更新 (`StatusBar.tsx`)

**旧显示**：💰 ¥0.00 (余额)
**新显示**：🔑 已激活 / 🔒 未激活

```typescript
<Tooltip title={activationStatus.message}>
  <span onClick={() => navigate('settings')}>
    {isActivated ? '🔑 已激活' : '🔒 未激活'}
  </span>
</Tooltip>
```

### 4. 密钥缓存机制验证

#### 前端流程 (`Settings.tsx`)
```
用户输入密钥 → saveApiKeyToGateway() → POST /v1/settings/keys
                                        ↓
                                  Gateway 写入 .env
                                        ↓
                                  刷新 process.env
                                        ↓
                                  返回成功 → 缓存到 localStorage
```

#### 后端处理 (`settings.ts`)
```typescript
// POST /v1/settings/keys
router.post('/v1/settings/keys', (req, res) => {
  const { provider, apiKey } = req.body;
  
  // 1. 写入 .env 文件
  writeEnvKey(envVar, apiKey);
  
  // 2. 刷新运行时环境变量
  process.env[envVar] = apiKey;
  
  // 3. 通知 router 重新检查 key 状态
  deps.router.recheckApiKeys();
  
  res.json({ ok: true });
});
```

**验证结果**：✅ 密钥缓存机制正常工作

## 💰 商业模式建议

### 方案 A：一次性密钥销售（推荐）

```
定价策略：
- 基础版：¥99  （永久使用，基础模型）
- 专业版：¥299 （永久使用，全部模型）
- 企业版：¥999 （永久使用 + 技术支持）
```

**优势**：
- 一次销售，长期收益
- 无需维护复杂的订阅系统
- 用户心理负担小

### 方案 B：年费制密钥

```
定价策略：
- 年度会员：¥199/年
- 终身会员：¥499（买断制）
```

**优势**：
- 持续现金流
- 用户粘性高

### 方案 C：混合模式（最灵活）

```
1. 免费层：内置免费模型（Agnes、智谱等）
2. 密钥层：添加密钥解锁全部模型
3. 高级层：微信私域提供定制服务
```

## 🎓 总结

### 核心认知转变

```
❌ 旧思维：我们是"平台"，要管理用户的钱
✅ 新思维：我们是"工具"，提供更好的使用体验
```

### 商业价值

1. **零风险** — 不碰资金，不会亏钱
2. **轻运营** — 不需要复杂的财务系统
3. **高转化** — 微信私域，信任度高
4. **可持续** — 一次性投入，持续产出

### 技术优势

1. **简单可靠** — 密钥即权限，逻辑清晰
2. **易于维护** — 不需要对接支付系统
3. **用户友好** — 透明计费，无隐藏费用
4. **扩展性强** — 可随时调整商业模式
