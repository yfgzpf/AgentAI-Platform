## 一、前端：技术事实 ↔ 产品含义

## 四、技能体系：技术现状 ↔ 产品资产化路径

| 技术现状（架构师实测） | 产品资产化路径（产品经理提议） | 协同方案 |
|----------------------|----------------------------|---------|
| 四处来源并存：`packages/agentai-skills/`（Python）+ 根 `skills/` + `gateway/src/skills/` + `SkillOpt/` | 产物本地存储（`~/.agentai/evolution/*.jsonl`），**零迁移成本** | 统一注册契约（manifest + 唯一入口），四处改 provider 注入 |
| `skill-manager.ts` **仅 85 行**，治理层实质缺位 | 进化不可见、不可分享、不可交易 → 无网络效应 | 扩 manager 为真生命周期管理器（注册/校验/启停/溯源） |
| 技能市场 12 文件中 6 个是 demo/mock/test | "先有鸡后有蛋"，现在做市场是错时序 | 用 feature-flag 关掉半成品，不进主链路 |
| **技能自进化疑似无质量闸门**（evolver 366行 + creator 251行，未见进化后评估/回滚配对） | 无闸门的自进化会积累劣化技能 | **架构师补质量闸门 + 产品经理补资产化 = 真护城河** |

**协同结论（最关键的交叉点）**：
- 架构师说"自进化最独特，但缺质量闸门（技术：进化变好还是变坏无人判）"
- 产品经理说"自进化唯一护城河潜力，但产物不可迁移（产品：用户零切换成本）"
- **两者是同一能力的两个缺失面**：
  - 技术面补**质量闸门**（进化前后跑评测集，不达标回滚）→ 解决"变好还是变坏"
  - 产品面补**资产化**（可见 / 可带走 `agent-profile.json` / 可分享链接）→ 解决"用户为什么留下"
  - 二者齐备，"自进化"才从功能变为资产，对冲"框架随模型贬值"与"切换成本为零"两大致命威胁

## 六、三方交叉：必须拍板的战略决策

### A. ⚠️ 中医叙事去留（真实冲突，需富哥裁决）
- **现状（工作记忆 2026-07-23）**：富哥已明确——项目名统一为「**PulseFlow（岐黄诊断引擎）**」，文档全面采用中医认知隐喻体系（望闻问切/辨证论治/君臣佐使/治未病），17 篇文档已完成中医化改造。
- **PM 视角（2026-08-05）**：中医叙事对开发者是减分项，海外完全 get 不到，建议从开头移到"设计理念"附录。
- **主理人中立观察**：若主打 PM 推荐的「国内政企/合规」尖锐场景，**"治未病/辨证论治"隐喻反而可与"合规前置、风险早诊"形成呼应**；但若主打通用开发者，则确属噪音。叙事粗细取决于 §六-B 的场景选择，**不必现在推翻已做的重构**。
- **建议**：场景落地（P0-2）后再定叙事粗细，当前保留 PulseFlow 品牌即可。

### B. 品牌统一（六选一）
- 候选：AgentAI / PulseFlow / 岐枢 / altas / 岐黄 / ALTES
- **建议**：对外品牌用 **PulseFlow**，技术命名空间留 **AgentAI**，彻底删除其余 4 个。纯执行力，零技术成本。

### C. 自进化资产化（架构师 + PM 协同，最高优先）
- 技术侧（架构师）：为 `skill-evolver`/`auto-skill-creator` 加**质量闸门**（进化前后跑评测集，不达标回滚）
- 产品侧（PM）：进化**可见**（进化档案页）+ **可带走**（`agent-profile.json` 导出导入）+ **可分享**（人格链接）
- 二者齐备 = 唯一护城河闭环

### D. 决策层自适应（合并注入点 + 按模型分流）
- 技术动作：歧义检测/置信度/元认知/自主修复的 `[SYSTEM]` 注入**合并为单一决策点**；强模型走轻框架、弱模型才启重补偿
- 一举三得：解注入冲突（架构师最高优先）+ 框架价值不随模型贬值（PM R3）+ 强模型下体验立升

### E. 免费上游单点（技术兜底）
- 动作：上游冗余 + 本地小模型（ollama）兜底，消除"卖点当天蒸发"风险（PM R2）
