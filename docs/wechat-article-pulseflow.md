## 中医讲究"四诊合参"

望其色、闻其声、问其症、切其脉，最后才开方。

PulseFlow 把这个思路用在了 AI 决策上：

```
望 → 任务感知：分析用户真实意图
闻 → 缺口分析：识别信息缺失点
问 → 主动追问：澄清歧义，确认需求
切 → 结构化诊断：评估置信度和风险
治 → 方案→执行→调方
```

| 场景 | 传统 AI | PulseFlow |
|------|---------|-----------|
| "帮我做个电商网站" | 直接写代码（经常跑偏） | 先问：需要哪些功能？用户系统？支付？ |
| "这段代码有问题" | 盲目修改 | 先诊断：语法？逻辑？性能？ |
| "优化这个函数" | 直接重写 | 先分析：瓶颈在哪？时间复杂度？ |

**不是慢，是精准。**

## 它会"记住"你

- **工作记忆**：当前任务上下文，每 10 轮自动摘要
- **持久记忆**：跨会话的偏好和经验，自动写入
- **行业洞察**：从对话中提取的行业知识，跨项目积累

```
第一次："我的项目用 pnpm，别用 npm"
    ↓
三天后："帮我装个依赖"
    ↓
自动使用 pnpm install ✅
```

AI 可以修改自己的行为规则，甚至运行时自创工具：

```
AI 尝试用 && 连接 PowerShell 命令 → 失败
    ↓
写入规则：PowerShell 不支持 &&，改用 ;
    ↓
下次对话自动加载 → 永远不再犯
```

## 免费模型优先，智能路由选优

| 模型 | 费用 | 适用场景 |
|------|------|----------|
| Agnes AI Flash | 🆓 免费 | 日常对话、代码生成 |
| GLM-4.7 Flash | 🆓 免费 | 文本任务、工具调用 |
| GLM-4.6V Flash | 🆓 免费 | 图片/视频分析 |
| DeepSeek V4 Pro | 💰 付费 | 代码审查、安全分析 |

**5 维智能路由**：复杂度 + 上下文适配 + 成本 + 成功率 + 延迟，自动选最优模型。

高风险操作（删文件、改配置）弹出审批卡片：

```
☑️ 信任此类操作（不再询问）
    ↓
后续同类操作自动放行 ✅
```

## 怎么开始？

```bash
git clone https://github.com/yfgzpf/AgentAI-Platform.git
cd AgentAI-Platform
pnpm install
pnpm dev
```

**不需要 API Key 就能开始聊天。** 免费模型已预配置，打开即用。

想解锁更强能力？设置页粘贴 Key → 自动生效 → 路由器智能分配任务。
