# PulseFlow：一个先诊断、再治疗的AI智能体

> 不是又一个聊天框，而是一个**会成长、有记忆、懂你行业**的AI工作伙伴。

---

## 一、传统AI的三大痛点

每次对话，都是从零开始。

你昨天教过它"用 pnpm 不用 npm"，今天它又忘了。  
你花了一周培养它的习惯，换个会话全清零。

更糟的是：

- 你说"优化这个函数"，它直接重写，不问瓶颈在哪
- 你说"帮我做个电商网站"，它直接写代码，不管你要哪些功能
- 你说"这段代码有问题"，它盲目修改，不先诊断

**为什么？因为传统AI没有"望闻问切"的诊断思维。**

---

## 二、PulseFlow的中医诊断法

PulseFlow 把中医"望闻问切"的思路用在了AI决策上：

```
望 → 任务感知：分析用户真实意图
闻 → 缺口分析：识别信息缺失点
问 → 主动追问：澄清歧义，确认需求
切 → 结构化诊断：评估置信度和风险
治 → 方案→执行→调方
```

| 场景 | 传统AI | PulseFlow |
|------|--------|-----------|
| "帮我做个电商网站" | 直接写代码（经常跑偏） | 先问：需要哪些功能？用户系统？支付？ |
| "这段代码有问题" | 盲目修改 | 先诊断：语法？逻辑？性能？ |
| "优化这个函数" | 直接重写 | 先分析：瓶颈在哪？时间复杂度？ |
| "帮我写个登录" | 复制粘贴示例 | 先问：用哪种认证？JWT/OAuth？ |

**不是慢，是精准。**

## 三、三层记忆架构

### 3.1 当前任务上下文

每次对话的上下文，每10轮自动摘要，防止长任务"失忆"。

### 3.2 跨会话偏好记忆

自动写入 `.agentai/memory.jsonl`，跨会话复用：

```
第一次："我的项目用 pnpm，别用 npm"
    ↓
三天后："帮我装个依赖"
    ↓
自动使用 pnpm install ✅
```

### 3.3 行业知识库

从对话中提取的行业知识，跨项目积累：

```
你说 "防水验收标准"
    ↓
AI 提取关键词 → 写入行业知识库
    ↓
下次聊装修 → 自动加载专业术语
```

---

## 四、自我进化能力

PulseFlow 支持 AI 自主修改行为规则，写入进化记忆：

```
AI 尝试用 && 连接 PowerShell 命令 → 失败
    ↓
写入规则：PowerShell 不支持 &&，改用 ;
    ↓
下次对话自动加载 → 永远不再犯
```

这让它真正成为一个**会成长**的伙伴，而不是每次重启就失忆的工具。

## 七、本地隐私安全

所有记忆、行业知识、对话历史都存储在本地：

- `.agentai/memory.jsonl` — 持久记忆
- `.agentai/evolved-rules.json` — 进化规则
- `knowledge/` — 行业知识库

**隐私安全，数据自主。**
