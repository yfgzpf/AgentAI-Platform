# PulseFlow 边界突破机会分析

> 日期：2026-08-28 ｜ 性质：战略研判（承接协同审查 2026-08-05"技术先还债、自进化资产化是生死线"）
> 结论：可行，但有前提——区分"工程债 / 补短板 / 真突破"三类，债先还，突破只押 2-3 个有骨架的方向

---

## 一、三类问题的分野（先分清，再投入）

| 类别 | 内容 | 性质 | 优先级 |
|---|---|---|---|
| **工程债** | 前端死代码 12.8%、巨型文件、决策层注入膨胀（R3 致命威胁）、AGENTS.md 失真 | 必须还，不是突破 | 最高（先做） |
| **补短板** | StepExecutor（施治引擎）缺失、处方-执行断链、连续状态监控 | 产品闭环的必要条件 | 次高 |
| **真突破** | 架构级自进化、处方-执行闭环（长期自主运行）、自验证闭环 | 差异化战场，骨架已有 | 战略押注 |

**判断原则**：在流沙上盖不了城堡。债不还，任何突破都会加速混乱。

---

## 二、真突破方向（3 个，均已有骨架）

### 方向一：架构级自进化 —— 从"改规则"到"改自己"

**现状（规则级，全行业普遍）**：发现低效 → 注入一条规则（evolve_prompt）→ 下次遵守。这是伪进化。

**突破（架构级，全行业空白）**：agent 对自己的架构有模型（元编程能力），能：
1. **诊断自己**：分析自己的工具调用模式、上下文注入效率、决策路径
2. **重构自己**：重组工具链（如将高频文件操作工具聚合为 DSL）、调整 prompt 分层/注入顺序、修改决策流程
3. **验证改造**：对比改造前后效果，回滚无效改造
4. **沉淀**：有效改造写入进化记忆，跨会话生效

**已有骨架**：`create_tool`（运行时自创工具）+ `evolve_prompt`（规则自修改）+ 进化记忆 + 启动感知 —— 三段各自为战，未连成"诊断→改造→验证→沉淀"闭环。

**价值**：从"AI 在框架内工作"跃迁到"AI 参与塑造框架本身"，这是自进化资产化的真正形态。

### 方向二：处方-执行闭环 + 连续状态监控 —— 从"会诊断"到"管到底"

**现状**：诊断子系统已完备（望闻问切），但 P0 缺失 StepExecutor（施治引擎），处方与执行断链。

**突破**：完整闭环 = 望闻问切（诊断）→ 辨证论治（处方）→ 用药施治（执行）→ 随访（连续监控），对应通用 agent 领域的"规划→执行→长期自主运行"。

**通用领域空白点**：跨会话、跨天的连续状态监控——agent 启动时记得昨晚任务、主动汇报、发现偏差自纠偏。`taskResumeStore` 已触及边缘。

**价值**：从"聊天机器人套壳"跃迁为"第一个能管一件事管到底的 agent"；同时是中医叙事最锋利的差异化刀（辨证→施治→随访的完整医理闭环）。

### 方向三：自验证闭环 —— 从"会干活"到"可信地干活"

**现状**：`auto_verify(tsc)` 只覆盖写文件单动作，是"写→验"单向补救；修复管道（8 种错误模式）是验证骨架但非强制前置。

**突破**：产出 → 自写测试 → 自跑 → 自评分 → 不达标自改 → 再验证 → 达标交付。验证从"事后补救"变为"产出的强制前置条件"。

**价值**：消除"AI 写的东西不敢信"的信任鸿沟——生产力工具的生死线。

---

## 三、伪方向警示（别踩）

| 伪方向 | 原因 |
|---|---|
| 继续堆功能 | 决策层注入膨胀已是 R3 致命威胁，加功能=加速死亡 |
| 全渠道铺开 | QQBot/微信/VSCode/Tauri 是放大器不是护城河；核心闭环不成立则全是空壳 |
| 追求"更像人的语气/人格" | 边际收益低；先解决可信度，再谈人格 |

---

## 四、路线建议（顺序不可跳步）

1. **还债**（1-2 月）：前端重构（见 FRONTEND_REFACTOR_PLAN）+ 决策层瘦身（合并 [SYSTEM] 注入为单一决策点）
2. **深耕方向二**（优先）：StepExecutor + 处方-执行闭环 + 连续状态监控 —— 产品闭环与差异化一石二鸟
3. **打通方向一**（基因工程）：把 create_tool/evolve_prompt/进化记忆串成"诊断→改造→验证→沉淀"闭环 —— 真正的自进化资产
4. **内化方向三**（穿插）：把自验证做成产出的强制前置，随还债过程逐步内化

---

## 五、可行性结论

**可行，且有独特优势**：
- 项目已具备多数框架没有的骨架（自进化三件套、元认知、置信度评估、256K 免费模型）
- 右上角（主动×进化）是全行业空白，项目已在边缘

**条件**：
- 必须先还债（工程债 + 决策层膨胀），否则突破在流沙上进行
- 只押 2-3 个方向，不撒胡椒面
- 每个突破点都要能"资产化"（可带走/可分享/可展示），呼应协同审查"自进化资产化是唯一生死线"
