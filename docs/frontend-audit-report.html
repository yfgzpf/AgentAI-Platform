"建立统一术语表，统一语言"两个 mode 同名不同义、isFreeModel 两处判断不一致、3 套 base URL——语言未统一

🗃️病灶三：状态层三套消息域 + 17 store —— "三个仓库存一份货" P1

共性结论：本项目的"浅模块"病在三处系统性传话——① 3 套消息 store 互相同步；② 类型层双份声明；③ 99 个 agentai:* 字符串事件让组件退化为 dispatch/监听节点（如 agentai:navigate 被 7 个文件各自 dispatch）。
