# RPA 获客解决方案调研报告

## 一、开源/免费 RPA 工具

### 1. TagUI (开源，推荐)
- **官网**: https://tagui.readthedocs.io/
- **GitHub**: https://github.com/aisingapore/TagUI
- **特点**: 
  - 完全开源免费
  - 支持中文自然语言编写脚本
  - 跨平台 (Windows/Mac/Linux)
  - 支持浏览器自动化和桌面应用
- **适用**: 网页版小红书、抖音、百度自动化

### 2. Automa (浏览器扩展，免费)
- **官网**: https://www.automa.site/
- **Chrome商店**: 可直接安装
- **特点**:
  - 可视化拖拽工作流
  - 无需编程
  - 社区有大量现成工作流
- **适用**: 快速搭建网页自动化

### 3. PyAutoGUI (Python库，免费)
- **GitHub**: https://github.com/asweigart/pyautogui
- **特点**:
  - 纯Python，易上手
  - 控制鼠标键盘
  - 屏幕截图和图像识别
- **适用**: 桌面客户端自动化（微信PC版）

### 4. Playwright (微软开源，免费)
- **官网**: https://playwright.dev/
- **特点**:
  - 微软出品，稳定可靠
  - 支持多浏览器
  - 自动等待，减少失败
- **适用**: 现代网页自动化

## 四、推荐技术方案

### 方案 A: 全开源方案 (推荐)
```
网页端 (小红书/抖音网页版):
  └── Playwright + Python
      ├── 登录自动化
      ├── 内容发布
      ├── 数据采集
      └── 消息回复

桌面端 (微信PC版):
  └── PyAutoGUI + OpenCV
      ├── 图像识别定位
      ├── 模拟鼠标点击
      ├── 键盘输入
      └── 朋友圈发布

调度系统:
  └── Python APScheduler
      ├── 定时任务
      ├── 任务队列
      └── 日志记录
```

### 方案 B: 混合方案 (快速落地)
```
网页端:
  └── Automa (可视化配置)
      ├── 从市场下载现成工作流
      ├── 修改适配自己的账号
      └── 导出分享

桌面端:
  └── PyAutoGUI
      └── 微信自动化脚本

集成:
  └── Python 调用 Automa 导出的工作流
```
