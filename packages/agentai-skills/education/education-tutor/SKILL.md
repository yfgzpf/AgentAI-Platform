# 教育辅导 📚

专业的 K12 / 大学 / 职业考试辅导工具，覆盖全学科。

## 核心功能

### 1. 学习计划生成

基于用户目标的智能学习计划:
```
输入:
- 目标: 高考 / 考研 / 雅思 / CPA / 法考
- 基础水平: 入门 / 进阶 / 高阶
- 时间: 3 个月 / 6 个月 / 1 年
- 每日可投入: 1h / 2h / 4h
```

**输出示例** (3 个月高考冲刺):
```
第 1 个月: 基础梳理
  - 数学: 必修 1-5 知识点清单
  - 语文: 文言文 + 古诗词
  - 英语: 3500 词汇 + 语法
  - 每日任务: 2 小时

第 2 个月: 真题训练
  - 历年高考真题 (近 5 年)
  - 错题本
  - 模拟考试 (每周 1 次)

第 3 个月: 冲刺 + 押题
  - 高频考点强化
  - 作文模板
  - 心理调适
```

### 2. 错题分析

**输入**: 错题 + 学生答案
**输出**: 错误类型 + 知识点漏洞 + 改进建议

**错误类型分类**:

| 类型 | 表现 | 改进 |
|------|------|------|
| 知识性错误 | 概念不懂 | 重新讲解 |
| 理解性错误 | 题意理解偏差 | 强化审题 |
| 粗心错误 | 计算失误 | 慢审题, 多检查 |
| 方法错误 | 解题方法不当 | 多练同类题 |
| 速度问题 | 会但慢 | 限时训练 |
| 心理问题 | 紧张失手 | 模拟考心态 |

**例题 (高考数学)**:
```
题: 已知 f(x) = x³ - 3x, 求 f(x) 在 [-1, 3] 上的最值
解:
1. f'(x) = 3x² - 3 = 3(x-1)(x+1)
2. 临界点: x = -1, x = 1
3. f(-1) = 2, f(1) = -2, f(3) = 18
4. 最大值 18 (x=3), 最小值 -2 (x=1)
```

## 学习方法论

### 费曼学习法
```
1. 选择概念
2. 假装教给别人
3. 遇到不懂回头学
4. 简化语言
```

### 番茄工作法
- 25 分钟专注
- 5 分钟休息
- 4 个番茄后长休息

### 艾宾浩斯遗忘曲线
- 1 天后复习
- 3 天后复习
- 7 天后复习
- 30 天后复习

### 主动回忆 vs 被动重读
- ✅ 做题 / 闭卷
- ❌ 反复看书
