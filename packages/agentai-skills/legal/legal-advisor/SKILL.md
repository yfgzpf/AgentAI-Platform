### 1. 合同审查 (Contract Review)

**审查维度**:

| 维度 | 检查点 |
|------|--------|
| 主体 | 当事人是否具备签约资格 |
| 标的 | 标的合法性、明确性 |
| 价款 | 金额、支付方式、发票 |
| 履行 | 期限、地点、方式 |
| 违约 | 违约金、定金、损失赔偿 |
| 争议 | 管辖、仲裁、适用法律 |
| 终止 | 解除条件、通知方式 |
| 保密 | 商业秘密保护 |
| 不可抗力 | 定义、范围、通知义务 |
| 转让 | 债权/债务/合同权利转让 |

- 🔴 高风险 (建议修改)
- 🟡 中风险 (建议协商)
- 🟢 低风险 (可接受)
- ✅ 良好实践

### 4. 诉讼策略

**诉讼流程**:
```
1. 诉前评估 (胜诉概率 / 成本)
2. 证据收集 (书证 / 物证 / 证人)
3. 起诉 / 应诉
4. 管辖异议 (如适用)
5. 财产保全 / 证据保全
6. 庭前调解
7. 开庭审理
8. 判决 / 裁定
9. 上诉 (如不服)
10. 执行
```

**管辖选择**:
- 被告住所地
- 合同履行地
- 协议管辖
- 仲裁条款 (排除法院)

**证据规则**:
- 谁主张谁举证
- 高度盖然性
- 举证倒置 (特殊情形)
- 电子数据证据规则

## 常见条款库

### 付款条款
```markdown
**付款方式**: 银行转账
**付款期限**: 验收合格后 30 日内
**逾期利息**: 万分之五/日
**发票**: 增值税专用发票
**收款账户**: [公司名] [银行] [账号]
```

### 违约金条款
```markdown
**违约金**: 合同总金额的 30%
**赔偿损失**: 实际损失 + 可得利益
**定金**: 合同总金额的 20% (不超过 20%)
**优先适用**: 违约金与定金不可并用
```

### 保密条款
```markdown
**保密期限**: 合同终止后 3 年
**保密范围**: 技术 / 商业 / 客户信息
**违约责任**: 赔偿 100 万元
**例外**: 公开信息 / 第三方合法披露
```

### 知识产权条款
```markdown
**权属**: 归甲方 / 乙方 / 共同所有
**许可**: 独占 / 排他 / 普通
**地域**: 中国 / 全球
**期限**: 与合同期一致 / 永久
```

### 争议解决
```markdown
**方式 1 (推荐)**: 仲裁 - 北京仲裁委员会
**方式 2**: 诉讼 - 甲方住所地人民法院
**适用法律**: 中华人民共和国法律
**语言**: 中文
```

## 法律风险清单

### 合同常见陷阱
- ❌ 主体不清 (自然人 vs 公司)
- ❌ 标的不明 (型号/规格缺失)
- ❌ 付款条件模糊 ("验收合格" 无标准)
- ❌ 违约金过低 (难以弥补损失)
- ❌ 管辖不利 (异地诉讼成本高)
- ❌ 违约责任不对等
- ❌ 知识产权约定不明
- ❌ 不可抗力范围过宽

### 用工常见风险
- ❌ 不签书面劳动合同 (双倍工资)
- ❌ 不缴社保 (补缴 + 滞纳金)
- ❌ 违法解除 (2N 赔偿)
- ❌ 强迫加班 (劳动监察)
- ❌ 工资低于最低标准
- ❌ 试用期过长 (超过 6 个月)
- ❌ 竞业限制不给补偿 (无效)

### 数据合规风险
- ❌ 未告知收集目的
- ❌ 未经同意收集
- ❌ 过度收集
- ❌ 跨境传输未评估
- ❌ 数据泄露未报告
- ❌ 儿童信息违规
