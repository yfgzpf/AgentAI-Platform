# 房地产顾问 🏠

专业的房地产评估、租约审查、贷款计算、市场分析工具。

## 核心功能

### 1. 房贷计算

**等额本息** (每月固定):
```
月供 = 贷款本金 × [月利率 × (1+月利率)^n] / [(1+月利率)^n - 1]
n = 还款月数
```

**等额本金** (每月递减):
```
每月本金 = 贷款本金 / 还款月数
每月利息 = 剩余本金 × 月利率
月供 = 每月本金 + 每月利息
```

**计算示例**:
```
贷款: 200 万
年限: 30 年 (360 月)
利率: 4.2% (LPR)
等额本息月供: ¥9,772
等额本金首月: ¥12,556 (逐月递减)
30 年总利息: ¥151.8 万 (本息) / ¥126 万 (本金)
```

**LPR 利率** (2024-2026):
| 年份 | 1年期 | 5年期+ |
|------|-------|--------|
| 2024 | 3.45% | 3.95% |
| 2025 | 3.10% | 3.60% |
| 2026 | 3.00% | 3.50% (预测) |

**公积金贷款**:
- 首套 5 年以上: 3.10%
- 二套 5 年以上: 3.575%

**首付比例** (中国):
| 城市 | 首套 | 二套 |
|------|------|------|
| 北京 | 35% | 40% (普宅 30%) |
| 上海 | 30% | 40% (普宅 35%) |
| 深圳 | 30% | 40% |
| 广州 | 30% | 40% |
| 一线平均 | 30-35% | 40% |
| 二线 | 20-25% | 30% |
| 三四线 | 20% | 30% |

### 2. 房价评估

**评估方法**:

**比较法 (市场比较法)**:
```
估价 = 近期成交 × 调整系数
调整系数 = 区位 × 楼层 × 朝向 × 装修 × 楼龄 × 配套
```

**收益法 (投资房)**:
```
估价 = 年净收益 / 资本化率
资本化率 = 无风险利率 + 风险溢价
```

**成本法 (新房)**:
```
估价 = 土地成本 + 建安成本 + 管理费 + 销售费 + 利润 + 税金
```

**特征价格法 (Hedonic)**:
```
ln(价格) = β₀ + β₁·面积 + β₂·楼层 + β₃·学区 + ... + ε
```

**评估因素权重** (典型):
| 因素 | 权重 |
|------|------|
| 地段 | 30% |
| 学区 | 20% |
| 交通 | 15% |
| 楼龄 | 10% |
| 楼层 | 5% |
| 朝向 | 5% |
| 装修 | 5% |
| 配套 | 5% |
| 其他 | 5% |

### 3. 租金回报率

**毛租金回报率**:
```
毛回报率 = 年租金 / 房价
一线城市: 1.5-2.0%
二线城市: 2.0-3.0%
三线城市: 2.5-4.0%
```

**净租金回报率** (扣除成本):
```
净回报率 = (年租金 - 持有成本) / 房价
持有成本 = 物业 + 维修 + 保险 + 出租中介费 + 空置期
```

**租售比健康值**: 1:200 - 1:300
(年租金 = 房价 / 200~300)

### 4. 租约审查

**关键条款**:

| 条款 | 注意事项 |
|------|----------|
| 租金 | 金额 + 支付方式 + 调整机制 |
| 押金 | 押一付一 / 押二付一 |
| 期限 | 起始 + 到期 + 续约 |
| 维修 | 责任划分 |
| 提前终止 | 违约金 |
| 转租 | 是否允许 |
| 改造 | 装修条款 |
| 宠物 | 是否允许 |
| 工商注册 | 是否可用于公司 |
| 备案 | 是否备案 (群租风险) |

**押一付三 / 押二付一**:
```
押 X 付 Y = 入住交 X 个月押金 + Y 个月租金
退租时: 押金扣除损坏后退还
```

**注意事项**:
- 房东身份证 + 房产证核对
- 二房东风险
- 群租房违规
- 商业用途登记
- 中介费 (北京: 租客付, 上海: 房东付)

### 5. 买卖合同

**关键条款**:

| 条款 | 关键点 |
|------|--------|
| 标的 | 房产证号 + 地址 + 面积 |
| 价款 | 总价 + 定金 + 首付 + 贷款 |
| 支付 | 时间节点 |
| 交付 | 时间 + 标准 (毛坯 / 精装) |
| 过户 | 时间 + 税费承担 |
| 违约 | 违约金 (通常 20%) |
| 户口 | 迁出条款 |
| 抵押 | 解押责任 |
| 学区 | 名额使用情况 |
| 物业 | 交割 + 欠费 |

**资金监管 (托管账户)**:
```
买方 → 监管账户 → 过户 → 卖方
保障双方, 防止骗贷 / 烂尾
```

**税费计算** (北京 90㎡ 二套):
```
契税: 3% (二套非普宅)
个税: 1% (满五唯一免)
增值税: 5.3% (满二免)
中介费: 2-3%
```

### 6. 市场分析

**市场指标**:

| 指标 | 含义 | 健康 |
|------|------|------|
| 价格指数 | 同比 / 环比 | 平稳 |
| 成交量 | 月成交套数 | 活跃 |
| 去化周期 | 库存 / 月成交 | 12-18 月 |
| 租售比 | 房价 / 年租金 | 200-300 |
| 房价收入比 | 房价 / 家庭年收入 | 6-10 |
| 套户比 | 套数 / 户数 | 1.1-1.2 |

**周期判断**:
```
繁荣期: 量价齐升, 抢购
调整期: 价跌量稳
萧条期: 量价齐跌, 观望
复苏期: 量先价后
```

**城市分级** (中国):
- 一线: 北上广深
- 新一线: 成都/杭州/重庆/苏州/武汉/西安/南京/天津/郑州/长沙/东莞
- 二线: 省会 + 计划单列
- 三线: 其他地级市
- 四五线: 县城

## 决策框架

**买房 vs 租房**:
```
买房划算当:
- 房价 / 家庭年收入 < 8
- 租售比 < 1:200
- 计划居住 5 年以上
- 利率低 (LPR 下行)
- 房价上涨预期

租房划算当:
- 工作不稳定
- 房价过高 (收入比 > 15)
- 利率高
- 房价下跌预期
- 1-2 年短期
```

**投资房评估**:
```
1. 现金流: 净租金 > 0
2. 增值: 区域有升值空间
3. 流动性: 易转手
4. 杠杆: 利率 / 租金 比
5. 持有: 5-10 年视角
6. 退出: 税费成本
```
