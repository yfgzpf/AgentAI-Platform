# 评论区截流获客系统 🎯

**2024年最有效的低成本获客黑科技**

## 核心原理

```
用户A在抖音发视频："装修花了30万，这些坑千万别踩"
    ↓
视频爆了，评论区1000+条评论
    ↓
用户B评论："我家也要装修了，求推荐"
用户C评论："正在找装修公司，哪家好？"
用户D评论："坐标北京，有靠谱的装修公司吗？"
    ↓
【我们的系统监控到这个视频】
    ↓
【自动采集这些高意向评论用户】
    ↓
【生成精准私信话术】
    ↓
【人工/自动私信触达】
    ↓
【引流到微信/电话】
    ↓
【成交转化】
```

## 为什么有效

| 传统方式 | 评论区截流 |
|---------|-----------|
| 自己发视频（需要粉丝基础） | 蹭别人的爆款流量 |
| 投广告（¥200-500/线索） | 免费监控，低成本触达 |
| 被动等客户 | 主动找意向客户 |
| 泛流量 | 精准意向（正在找装修） |

**真实效果：**
- 日监控视频：100-500条
- 日采集意向用户：50-200人
- 私信转化率：5-15%
- 日获客成本：¥10-30/人（远低于广告投放）

## 系统功能

### 1. 爆款视频监控
- 监控指定关键词的爆款视频
- 自动识别高互动视频（评论>100）
- 实时推送新爆款

### 2. 评论区采集
- 自动采集视频下所有评论
- 提取用户名、评论内容、点赞数
- 保存到数据库

### 3. 意向识别
- AI识别高意向评论
- 关键词匹配（"求推荐"、"哪家好"、"多少钱"）
- 意向评分（1-10分）

### 4. 私信话术生成
- 根据评论内容生成个性化话术
- 避免千篇一律
- 提高回复率

### 5. 批量触达
- 支持手动私信
- 支持自动化私信（需配合工具）
- 记录触达状态

## 使用流程

```
Step 1: 设置监控关键词
    - "装修"
    - "装修公司"
    - "装修避坑"
    - "老房翻新"
    - 地域词："北京装修"、"上海装修"

Step 2: 系统自动运行
    - 每小时扫描新视频
    - 识别爆款（播放量>10万或评论>100）
    - 采集评论区

Step 3: 查看意向用户
    - 系统展示高意向用户列表
    - 按意向分数排序
    - 显示评论内容和用户信息

Step 4: 生成话术并触达
    - 点击用户，生成私信话术
    - 复制话术，手动私信
    - 或调用自动化工具发送

Step 5: 跟进转化
    - 记录用户回复
    - 标记跟进状态
    - 引流到微信/电话
```

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| action | string | 是 | 操作类型 |
| platform | string | 是 | 平台：douyin/xiaohongshu/shipinhao |
| keywords | array | 是 | 监控关键词 |
| city | string | 否 | 地域限制 |

## 操作类型

### 开始监控
```json
{
  "action": "start_monitoring",
  "platform": "douyin",
  "keywords": ["装修", "装修公司", "装修避坑"],
  "city": "北京",
  "min_comments": 100
}
```

  "date": "2024-07-08",

## 风险提示

⚠️ **平台风险：**
- 频繁私信可能触发风控
- 建议控制频率：每小时<10条
- 使用老账号，新账号易被封

⚠️ **法律风险：**
- 遵守平台用户协议
- 不要发送垃圾信息
- 尊重用户隐私

⚠️ **效果波动：**
- 平台算法会调整
- 需要持续优化策略
- 不能100%保证效果

## 与RPA的区别

| 维度 | 传统RPA | 评论区截流 |
|------|--------|-----------|
| 目标 | 自己发内容 | 蹭别人流量 |
| 成本 | 高（需要养号） | 低（监控即可） |
| 精准度 | 泛流量 | 精准意向 |
| 风险 | 封号（主动操作） | 较低（被动监控） |
| 效果 | 差 | 好 |
