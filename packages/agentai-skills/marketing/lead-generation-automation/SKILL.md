# 自动化获客技能

基于browser-use的评论区截流获客自动化方案。

## 核心能力

### 1. 录制获客流程
- 录制用户在抖音/小红书的操作
- 自动识别关键步骤（搜索、筛选、进入视频、采集评论）
- 生成可重复执行的技能脚本

### 2. 智能执行
- 按录制流程自动执行
- 智能等待页面加载
- 异常处理（弹窗、登录、验证码）
- 随机延迟，模拟真人

### 3. 数据采集
- 自动提取评论区用户信息
- 智能识别高意向评论
- 按地域/需求筛选
- 保存到线索库

### 4. 自动跟进
- 生成个性化私信话术
- 自动发送（可选）
- 记录跟进状态

## 使用流程

### 方式1：录制模式（推荐）

```
1. 用户说："录制抖音获客流程"
2. 系统打开浏览器，进入抖音
3. 用户执行：搜索→筛选→进入视频→滚动评论→标记意向用户
4. 系统录制每一步操作
5. 用户说："保存录制"
6. 系统生成技能脚本
7. 用户说："执行获客任务，关键词'装修'，采集10条"
8. 系统自动重复录制流程，批量获客
```

### 方式2：配置模式

```
配置获客任务：
- 平台：抖音
- 关键词：装修
- 地域：北京
- 筛选条件：评论数>100，发布时间<7天
- 采集数量：20条
- 意向关键词：求推荐、多少钱、哪家好

系统自动执行获客流程
```

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| mode | string | 是 | 模式：record/execute/config |
| platform | string | 是 | 平台：douyin/xiaohongshu |
| keyword | string | 是 | 搜索关键词 |
| location | string | 否 | 地域筛选 |
| maxLeads | number | 否 | 最大采集数，默认10 |
| intentKeywords | array | 否 | 意向关键词列表 |
| autoFollowUp | boolean | 否 | 是否自动跟进，默认false |

## 注意事项

1. **频率控制**: 避免操作过于频繁，建议间隔5-10秒
2. **异常处理**: 遇到验证码或登录提示会暂停，需人工处理
3. **数据安全**: 采集的数据仅保存在本地，不上传云端
4. **合规使用**: 遵守平台规则，仅用于正当商业用途
