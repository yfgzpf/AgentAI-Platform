# 成熟获客方法AI助手 🎯

**辅助而非替代，让有效的获客方法更高效**

## 核心理念

❌ 不追求全自动RPA（封号风险、效果差）  
✅ 辅助人工执行（提高效率、保证质量）

## 功能模块

### 1. 老客户转介绍助手

**功能：**
- 生成转介绍话术
- 设计转介绍奖励方案
- 自动提醒跟进时间
- 计算转介绍ROI

**使用：**
```
"生成老客户转介绍话术，完工3天后跟进"
"设计转介绍奖励方案，预算500元/单"
"计算本月转介绍ROI"
```

### 2. 小区深耕助手

**功能：**
- 生成小区专属内容
- 设计小区活动方案
- 制定小区攻坚计划
- 跟踪小区进度

**使用：**
```
"生成XX小区专属装修攻略"
"设计小区工地参观日活动"
"制定XX小区3个月攻坚计划"
```

### 3. 内容营销助手

**功能：**
- 生成小红书标题和文案
- 生成抖音视频脚本
- 提供内容日历建议
- 分析内容效果

**使用：**
```
"生成10个小红书标题，关于老房翻新"
"生成抖音视频脚本，主题是装修避坑"
"制定下周内容发布计划"
```

### 4. 异业联盟助手

**功能：**
- 生成合作方案
- 设计联名活动
- 计算分成比例
- 跟踪合作效果

**使用：**
```
"生成与瓷砖店的合作方案"
"设计周末联合促销活动"
"计算最优分成比例"
```

### 5. 客户管理助手

**功能：**
- 客户信息记录
- 跟进提醒
- 意向分析
- 成交预测

**使用：**
```
"记录客户信息：张三，100平，预算20万"
"提醒我3天后跟进李四"
"分析王五的成交概率"
```

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| action | string | 是 | 操作类型 |
| context | object | 否 | 上下文信息 |

## 操作类型

### 生成转介绍话术
```json
{
  "action": "generate_referral_script",
  "context": {
    "customer_name": "张先生",
    "project_type": "全屋翻新",
    "budget": "15万",
    "days_after_completion": 3
  }
}
```

### 生成小区内容
```json
{
  "action": "generate_community_content",
  "context": {
    "community_name": "万科金色家园",
    "city": "北京",
    "house_type": "90平三室",
    "pain_points": ["收纳不足", "采光差"]
  }
}
```

### 生成小红书内容
```json
{
  "action": "generate_xiaohongshu_content",
  "context": {
    "topic": "老房翻新",
    "style": "避坑指南",
    "local_city": "上海"
  }
}
```

### 设计合作方案
```json
{
  "action": "design_partnership",
  "context": {
    "partner_type": "瓷砖店",
    "partner_name": "马可波罗",
    "target": "互相带客"
  }
}
```

## 使用场景

### 场景1：老客户转介绍
```
销售："生成转介绍话术，客户张先生，刚完工"
AI：生成话术 + 提醒3天后跟进 + 计算奖励

销售：拨打电话，使用AI生成的话术
客户：同意推荐朋友
销售：记录推荐信息
AI：自动提醒跟进推荐客户
```

### 场景2：小区内容营销
```
营销："生成XX小区专属内容"
AI：生成3篇不同角度的内容

营销：人工审核修改
营销：发布到小红书/业主群
AI：记录发布时间，提醒互动
```

### 场景3：异业合作
```
老板："设计瓷砖店合作方案"
AI：生成合作方案 + 分成建议 + 话术

老板：与瓷砖店洽谈
双方：确定合作细节
AI：生成合作协议模板
```

## 与全自动RPA的区别

| 维度 | 全自动RPA | 本助手 |
|------|----------|--------|
| 自动化程度 | 90% | 30% |
| 封号风险 | 高 | 无 |
| 内容质量 | 低（机器味） | 高（人工审核） |
| 客户体验 | 差 | 好 |
| 实际效果 | 差 | 好 |
| 实施难度 | 高 | 低 |

4. **客户关系** - 真诚服务，建立信任
