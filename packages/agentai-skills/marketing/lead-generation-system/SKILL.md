# 全渠道自动化获客系统 🎯

装修行业获客成本高、转化难？让AI帮你实现自动化获客！

## 核心痛点

| 痛点 | 传统方式 | AI自动化 |
|------|---------|---------|
| 内容生产 | 人工撰写，效率低 | AI批量生成，日更10篇+ |
| 多平台运营 | 逐个平台发布 | 一键分发全渠道 |
| 线索收集 | 手动记录，易遗漏 | 自动捕获，实时入库 |
| 线索培育 | 人工跟进，成本高 | AI自动培育，7x24小时 |
| 转化跟进 | 销售遗忘、延迟 | 自动提醒、智能分配 |

## 获客渠道矩阵

### 1. 微信生态（私域核心）
- **公众号**：专业文章、案例展示
- **视频号**：短视频、直播
- **朋友圈**：日常内容、活动海报
- **微信群**：业主群、团购群
- **小程序**：在线报价、预约量房

### 2. 抖音生态（流量红利）
- **短视频**：装修知识、避坑指南
- **直播**：工地直播、材料选购
- **DOU+**：精准投放

### 3. 小红书（种草平台）
- **图文笔记**：装修日记、好物分享
- **视频笔记**：Room Tour、改造前后
- **话题运营**：#装修避坑 #我的装修日记

### 4. 百度搜索（精准流量）
- **SEO文章**：长尾关键词覆盖
- **百度知道**：问答营销
- **百家号**：内容分发

### 5. 线下渠道（本地流量）
- **小区地推**：新楼盘驻点
- **异业合作**：建材商、家具店
- **老客户转介绍**：裂变活动

## 线索评分模型

| 行为 | 分值 | 说明 |
|------|------|------|
| 关注公众号 | +5 | 基础兴趣 |
| 阅读文章 | +3/篇 | 内容兴趣 |
| 点赞 | +5 | 轻度认可 |
| 评论 | +10 | 主动互动 |
| 分享 | +20 | 高意向 |
| 私信咨询 | +30 | 购买意向 |
| 留电话 | +50 | 强意向 |
| 预约量房 | +100 | 成交意向 |

**评分等级：**
- 0-30分：冷线索（长期培育）
- 31-60分：温线索（内容推送）
- 61-80分：热线索（销售跟进）
- 81-100分：高意向（优先跟进）

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| action | string | 是 | 操作类型 |
| channel | string | 否 | 目标渠道 |
| topic | string | 否 | 内容主题 |
| budget | number | 否 | 投放预算 |

## 操作类型

### 生成内容
```json
{
  "action": "generate_content",
  "channel": "wechat",
  "content_type": "article",
  "topic": "卫生间防水",
  "target_audience": "装修业主"
}
```

### 分发内容
```json
{
  "action": "distribute",
  "content_id": "article_001",
  "channels": ["wechat", "douyin", "xiaohongshu"],
  "schedule": "2024-07-10T20:00:00"
}
```

### 分析线索
```json
{
  "action": "analyze_leads",
  "date_range": "2024-07-01_to_2024-07-07",
  "channel": "all"
}
```

### 生成报告
```json
{
  "action": "generate_report",
  "report_type": "weekly",
  "channels": ["wechat", "douyin"]
}
```

## 核心指标

| 指标 | 说明 | 目标值 |
|------|------|--------|
| 内容产出量 | 每周原创内容数 | ≥10篇 |
| 内容曝光量 | 各渠道总曝光 | ≥10万/周 |
| 线索获取量 | 每周新增线索 | ≥50个 |
