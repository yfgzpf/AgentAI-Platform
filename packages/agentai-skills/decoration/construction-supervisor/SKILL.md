# 施工监理助手 👷

装修全流程监理指导，让施工质量有保障。

## 自动触发场景

### 1. 施工前准备
```
User: "水电改造要注意什么"
→ 提供水电施工标准和验收清单
```

### 2. 验收检查
```
User: "瓷砖铺好了怎么验收"
→ 提供泥瓦验收标准和检查方法
```

### 3. 质量问题
```
User: "墙面开裂是什么原因"
→ 诊断问题原因并提供解决方案
```

### 4. 进度管理
```
User: "装修进度到哪里了"
→ 根据当前阶段提供下一步指导
```

## 施工阶段

### 阶段 1：拆除改造
| 检查项 | 标准 | 常见问题 |
|--------|------|---------|
| 拆除范围 | 按图纸，不破坏承重墙 | 误拆承重墙 |
| 垃圾清运 | 日产日清 | 堆积影响施工 |
| 成品保护 | 门窗电梯保护到位 | 损坏公共设施 |

### 阶段 2：水电改造 ⭐关键
| 检查项 | 标准 | 验收方法 |
|--------|------|---------|
| 水管打压 | 0.8-1.0MPa，30分钟不掉压 | 压力表检测 |
| 电路绝缘 | 线间绝缘≥0.5MΩ | 摇表测试 |
| 强弱电分离 | 间距≥50cm，交叉处屏蔽 | 目测+尺量 |
| 线管固定 | 管卡间距≤80cm | 目测 |
| 插座高度 | 标准高度±5mm | 尺量 |
| 配电箱 | 回路标识清晰 | 目测 |

**水电验收清单**：
- [ ] 水管打压测试合格
- [ ] 电路绝缘测试合格
- [ ] 强弱电分离符合规范
- [ ] 插座开关位置正确
- [ ] 配电箱回路清晰
- [ ] 留存水电走向图

### 阶段 3：泥瓦工程
| 检查项 | 标准 | 常见问题 |
|--------|------|---------|
| 防水 | 卫生间墙面≥1.8m，地面全做 | 漏水 |
| 闭水试验 | 48小时无渗漏 | 楼下检查 |
| 瓷砖空鼓 | 空鼓率≤5% | 空鼓锤检测 |
| 平整度 | 2m靠尺误差≤3mm | 靠尺检测 |
| 阴阳角 | 90度±3度 | 角尺检测 |
| 勾缝 | 饱满、颜色一致 | 目测 |

### 阶段 4：木工工程
| 检查项 | 标准 | 常见问题 |
|--------|------|---------|
| 吊顶龙骨 | 间距≤40cm，牢固 | 晃动检查 |
| 石膏板 | 接缝V型槽，错缝安装 | 开裂 |
| 柜子尺寸 | 与设计图误差≤5mm | 尺量 |
| 五金安装 | 牢固、开关顺畅 | 试用 |

### 阶段 5：油漆工程
| 检查项 | 标准 | 常见问题 |
|--------|------|---------|
| 墙面平整 | 2m靠尺误差≤3mm | 靠尺+灯光 |
| 阴阳角 | 平直、无崩边 | 目测 |
| 涂刷均匀 | 无流坠、无刷痕 | 目测 |
| 颜色一致 | 无色差 | 自然光下看 |

### 阶段 6：安装收尾
| 检查项 | 标准 | 常见问题 |
|--------|------|---------|
| 门窗安装 | 开关顺畅、密封好 | 试用 |
| 卫浴安装 | 水平、牢固、无渗漏 | 试水 |
| 灯具开关 | 位置正确、功能正常 | 试用 |
| 地板安装 | 无缝隙、踩踏无异响 | 踩踏 |

## 质量诊断

### 墙面问题
| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 开裂 | 基层处理不当/结构沉降 | 铲除重做，加网格布 |
| 起皮 | 潮湿/底漆不配套 | 找出潮源，重新涂刷 |
| 发霉 | 渗水/通风差 | 防水处理，除霉重刷 |

### 地面问题
| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 空鼓 | 铺贴不当/基层问题 | 重新铺贴 |
| 起拱 | 伸缩缝不足/受潮 | 切开重铺，留足缝隙 |
| 异响 | 地面不平/龙骨松动 | 找平或加固龙骨 |

### 水电问题
| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 漏水 | 接头松动/管材问题 | 找到漏点，重新连接 |
| 跳闸 | 短路/过载/漏电 | 检查线路，更换空开 |
| 电压不稳 | 线路老化/接触不良 | 更换线路，紧固接头 |
