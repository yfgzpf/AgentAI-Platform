# 智能报价生成器 💰

自动生成专业装修报价单，让谈单更高效。

## 核心能力

### 1. 智能报价计算
```
输入：100平米，三室两厅，现代简约，中等档次
输出：详细报价单（人工+材料+管理，分项明细）
```

### 2. 多档次选择
- **经济型**：800-1200元/㎡
- **舒适型**：1500-2500元/㎡
- **豪华型**：3000元/㎡以上

### 3. Excel导出
- 专业报价单格式
- 公司Logo、联系方式
- 分项小计、总计
- 付款计划

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| area | number | 是 | 建筑面积（㎡） |
| rooms | string | 否 | 户型，如"3室2厅1卫" |
| style | string | 否 | 装修风格 |
| level | string | 否 | 档次：经济/舒适/豪华 |
| city | string | 否 | 城市（影响人工费） |
| special_items | array | 否 | 特殊项目 |
