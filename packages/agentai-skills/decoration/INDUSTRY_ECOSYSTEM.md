## 九、技能调用链路示例

### 场景：客户从咨询到成交

```
1. 获客阶段
   客户："我在小红书看到你们的案例，想了解装修"
   → content-marketing: 展示相关案例
   → lead-capture: 录入客户信息
   → lead-scoring: 评分（高意向）
   → appointment-scheduler: 预约量房

2. 谈单阶段
   客户："我家100平，预算15万，喜欢简约风"
   → requirement-interview: 结构化需求
   → budget-analyzer: 预算分配建议
   → style-recommender: 推荐北欧简约
   → material-selector: 推荐性价比材料
   → quotation-generator: 生成报价单

3. 设计阶段
   客户："帮我设计一下衣柜和橱柜"
   → cad-ai-designer: 设计衣柜
   → cad-ai-designer: 设计橱柜
   → 3d-visualization: 生成效果图
   → material-calculator: 计算材料用量

4. 跟进阶段
   客户："水电做完了吗？"
   → construction-supervisor: 查询进度
   → progress-tracker: 生成进度报告
   → daily-report: 发送施工日报

5. 成交阶段
   客户："确定签约"
   → contract-generator: 生成合同
   → payment-scheduler: 制定付款计划
   → warranty-manager: 说明质保条款

6. 交付阶段
   → final-inspection: 竣工验收
   → handover-document: 交付文档
   → project-archive: 项目归档

7. 售后阶段
   客户："地板有点问题"
   → warranty-claim: 质保申请
   → repair-scheduler: 预约维修
   → satisfaction-survey: 满意度调查
```
