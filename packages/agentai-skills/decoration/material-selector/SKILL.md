# 材料选型助手 🏗️

智能推荐装修材料，让选材不再困难。

## 自动触发场景

### 1. 预算选材
```
User: "10万预算怎么选材料"
→ 自动推荐性价比最优的材料组合
```

### 2. 风格匹配
```
User: "北欧风格用什么地板"
→ 推荐适合北欧风的地板材质和品牌
```

### 3. 空间选材
```
User: "卫生间瓷砖怎么选"
→ 根据防滑、防水、美观推荐瓷砖
```

### 4. 环保优先
```
User: "要最环保的涂料"
→ 推荐环保等级最高的涂料品牌
```

## 选型维度

### 1. 预算匹配
- 经济型：总价控制在 800-1200元/㎡
- 舒适型：总价控制在 1500-2500元/㎡
- 豪华型：总价 3000元/㎡以上

### 2. 风格匹配
- 现代简约：灰色系、白色系
- 北欧风：原木色、浅色系
- 中式：木纹、暖色系
- 轻奢：大理石纹、金属质感

### 3. 环保等级
- E0级：甲醛≤0.05mg/m³
- E1级：甲醛≤0.124mg/m³
- 法国A+：TVOC极低
- 蓝天使：德国环保认证

### 4. 功能需求
- 防滑：卫生间、厨房
- 防水：卫生间、阳台
- 耐磨：客厅、走廊
- 静音：卧室、书房
