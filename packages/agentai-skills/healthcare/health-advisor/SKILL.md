# 健康顾问 🏥

专业的健康咨询、症状自查、药品查询、慢病管理工具。

## ⚠️ 重要声明

**本工具不替代医生诊疗**, 仅提供基础健康知识。急重症请立即就医。

**紧急情况请拨打**:
- 🚑 中国: 120
- 🚑 美国: 911
- 🚑 欧洲: 112

## 核心功能

### 1. 症状自查 (Symptom Checker)

**红旗症状 (Red Flags) — 立即就医**:
- ⚠️ 胸痛 + 放射至左臂/下颌
- ⚠️ 突然剧烈头痛 (雷击样)
- ⚠️ 偏瘫 / 失语 / 视力骤降
- ⚠️ 呼吸困难 + 嘴唇发紫
- ⚠️ 大量咯血 / 呕血
- ⚠️ 持续高热 > 40°C
- ⚠️ 抽搐 / 意识丧失
- ⚠️ 严重外伤 / 大出血
- ⚠️ 急性腹痛 + 板状腹
- ⚠️ 妊娠期阴道出血

**常见症状分流**:

| 症状 | 自我观察 | 建议就医 |
|------|----------|----------|
| 头痛 | 偶发, 休息可缓解 | 持续/加重/呕吐 |
| 发热 | < 38.5°C, 无其他症状 | > 39°C 持续 3 天 |
| 咳嗽 | < 2 周 | > 4 周 / 痰中带血 |
| 腹痛 | 轻微, 可缓解 | 剧烈/持续/定位明确 |
| 腹泻 | < 3 天, 无脱水 | > 3 天 / 脱水 / 便血 |
| 胸闷 | 一过性 | 持续 / 伴胸痛 / 气促 |

### 2. 检验报告解读

**血常规**:
| 指标 | 正常范围 | 偏高 | 偏低 |
|------|----------|------|------|
| WBC 白细胞 | 4-10 ×10⁹/L | 感染/炎症 | 免疫低下 |
| RBC 红细胞 | 男 4.0-5.5 / 女 3.5-5.0 | 脱水/真性红细胞增多 | 贫血 |
| HGB 血红蛋白 | 男 120-160 / 女 110-150 g/L | 脱水 | 贫血 |
| PLT 血小板 | 100-300 ×10⁹/L | 血栓风险 | 出血风险 |
| NEUT 中性粒 | 50-70% | 细菌感染 | 病毒感染 |
| LYMPH 淋巴 | 20-40% | 病毒感染 | 免疫缺陷 |

**生化全项**:
| 指标 | 正常 | 临床意义 |
|------|------|----------|
| ALT 谷丙转氨酶 | < 40 U/L | 肝功能 |
| AST 谷草转氨酶 | < 40 U/L | 肝/心肌 |
| BUN 尿素氮 | 2.9-8.2 mmol/L | 肾功能 |
| Cr 肌酐 | 男 54-106 / 女 44-97 μmol/L | 肾功能 |
| Glu 血糖 | 空腹 3.9-6.1 mmol/L | 糖尿病 |
| TG 甘油三酯 | < 1.7 mmol/L | 心血管风险 |
| TC 总胆固醇 | < 5.2 mmol/L | 心血管风险 |
| HDL 高密度脂蛋白 | > 1.0 mmol/L | 保护因素 |
| LDL 低密度脂蛋白 | < 3.4 mmol/L | 风险因素 |

**糖化血红蛋白 (HbA1c)**:
- < 5.7% 正常
- 5.7-6.4% 糖尿病前期
- ≥ 6.5% 糖尿病

### 3. 药品查询

**查询维度**:
- 通用名 / 商品名
- 适应症
- 用法用量
- 不良反应
- 禁忌
- 相互作用
- 妊娠分级
- 储存条件

**常见药物速查**:

| 类别 | 通用名 | 用途 |
|------|--------|------|
| 降压 | 氨氯地平 | 高血压 |
| 降糖 | 二甲双胍 | 2 型糖尿病 |
| 降脂 | 阿托伐他汀 | 高胆固醇 |
| 抗血小板 | 阿司匹林 | 心血管预防 |
| 抗凝 | 华法林 | 血栓预防 |
| 胃药 | 奥美拉唑 | 胃酸过多 |
| 抗生素 | 阿莫西林 | 细菌感染 |
| 止痛 | 对乙酰氨基酚 | 轻中度疼痛 |

⚠️ **用药安全**:
- 处方药必须医生开具
- 不要自行调整剂量
- 注意药物相互作用
- 过敏史必须告诉医生
- 妊娠期用药需特别谨慎

### 4. 慢病管理

**高血压管理**:
- 目标: < 130/80 mmHg
- 低盐饮食 (< 5g/日)
- 规律运动 (150 分钟/周)
- 戒烟限酒
- 规律服药, 不擅自停药
- 家庭血压监测

**糖尿病管理**:
- 目标 HbA1c < 7%
- 饮食控制 (碳水化合物)
- 运动 (餐后 30 分钟)
- 血糖监测
- 足部护理
- 眼底 / 肾功 / 神经定期检查

**高血脂管理**:
- LDL 是主要目标
- 他汀类一线
- 饮食: 减少饱和脂肪
- 增加膳食纤维
- 运动 + 减重

### 5. 运动饮食

**运动处方 (FITT 原则)**:
- F (Frequency): 3-5 次/周
- I (Intensity): 中等强度 (心率 60-80%)
- T (Time): 30-60 分钟/次
- T (Type): 有氧 + 抗阻

**心率计算**:
- 最大心率 = 220 - 年龄
- 减脂区: 60-70% × 最大心率
- 有氧区: 70-80% × 最大心率

**饮食建议**:
- 每日饮水 1500-2000 ml
- 蔬菜 300-500g
- 水果 200-350g
- 蛋白质 1.0-1.2g/kg 体重
- 限制添加糖 < 25g
- 限制盐 < 5g
- 限制油 25-30g

## 健康指标自查

### 体重 (BMI)
- 偏瘦: < 18.5
- 正常: 18.5-23.9
- 超重: 24-27.9
- 肥胖: ≥ 28

### 腰围
- 男 < 90cm
- 女 < 85cm

### 血压
- 正常: < 120/80
- 正常高值: 120-139/80-89
- 高血压: ≥ 140/90

### 血脂
- TC < 5.2
- TG < 1.7
- LDL < 3.4
- HDL > 1.0
