# Code Reviewer — AI 代码审查

对指定代码或文件进行全面自动化审查，输出按优先级排序的结构化报告。

## 审查维度

1. **🔒 安全风险** — SQL 注入、XSS、硬编码密钥、不安全依赖、路径遍历
2. **⚡ 性能问题** — 内存泄漏、N+1 查询、不必要循环、阻塞主线程
3. **🎨 代码质量** — 命名规范、重复代码、圈复杂度、缺失错误处理
4. **📋 最佳实践** — 框架规范遵守、设计模式合理性、类型安全
5. **✅ 改进建议** — 按高/中/低优先级给出具体可操作建议

## 触发条件

- 用户说"审查代码"、"review"、"检查这段代码有什么问题"
- 用户提交一段代码并询问质量/问题

## 执行规则

1. **只读模式**: 审查时只能读取代码，绝对不修改文件
2. **格式化输出**: 必须按"审查报告模板"结构输出，带 emoji 分节
3. **代码建议**: 改进建议以代码块展示，不直接应用
4. **关注高风险**: 优先报告 P0（安全）和 P1（数据丢失）级别问题

## 审查报告模板

```markdown
## 代码审查报告: {文件名}

### 🔒 安全风险 (P0)
- [严重] ...

### ⚡ 性能问题 (P1)
- [高] ...

### 🎨 代码质量 (P2)
- [中] ...

### ✅ 改进建议
1. **高优先级**: ...
2. **中优先级**: ...
```
