# 农房规划合规速查（Compliance Checklist）

**用途**：农村自建房规划阶段的第一道筛子。出方案前先钉死这五条硬约束，
否则后面全部返工。

> ⚠️ **最高优先事项**：`建筑面积上限` 与 `建筑限高` 两项，
> **必须向乡镇审批窗口 / 自然资源部门当面核实并取得书面依据**。
> 本页数据为省级文件口径，地方执行值可能不同。

---

## 一、五条硬约束（先钉死）

| # | 项 | 省级口径 | 依据 | 常见误判 |
|---|---|---|---|---|
| 1 | **层数** | 不得超过 **3 层** | 闽政办〔2011〕189 号 第三十七条 | 业主常提"4 层"，须先核 |
| 2 | **建筑面积** | 每户控制在 **300 ㎡以内** | 同上 | 业主常提"400 平"，**未见省级依据** |
| 3 | **宅基地面积** | **80 ~ 120 ㎡**；利用空闲地或原旧住宅改建的，可增加**不超过 30 ㎡** | 福建省土地管理条例 第四十二条 | 超红线部分须单独报批并取得村委、四邻书面意见 |
| 4 | **覆盖率** | 农村宅基地常规 **≤80%** | 地方惯例 | 常被忽略；基底 = 首层外墙围合面积 |
| 5 | **层高** | 一般 **3 米左右** | 闽政办 189 号 | 中堂 4.5 m 这类"单层挑高"易踩 |

### 交叉验证过的地方文件（2024—2025）

| 地区 | 时间 | 口径 |
|---|---|---|
| 南平市 | 2025.06 通知 | 重申 3 层 / 300 ㎡ |
| 福鼎市 | 2025 示范农房 | 300 ㎡ / 高度 ≤12.3 m |
| 厦门市 | 2024 实施意见 | 宅基地 ≤90 ㎡ → 3 层 / 270 ㎡；宅基地 <80 ㎡ 才可 4 层 / 300 ㎡ |

### 两条合法的"多出空间"途径（厦门口径，可争取）

| 途径 | 条件 | 效果 |
|---|---|---|
| **坡屋顶阁楼** | 起坡点不高于顶层屋面 **0.5 m**、坡屋顶高度 **≤2.2 m** | **不计层数、不计建筑面积**，可做休闲茶室 |
| **底层架空层** | 层高 **≤2.2 m** | **不计层数、不计建筑面积**，临河地块兼可防潮 |

**总高校核**：3 层含坡屋顶 ≤ **14 m**；无架空层 ≤ **11.8 m**。
（严禁以下挖架空层变相增加层高，会被移送执法处理。）

## 二、功能尺度要求

| 项 | 要求 | 备注 |
|---|---|---|
| 卧室 / 起居室净高 | ≥ **2.40 m** | 局部 ≥2.10 m 时该部分面积 ≤1/3 |
| 起居室面积 | ≥ **10 ㎡** | |
| 双人卧室面积 | ≥ **9 ㎡** | 单人间可放宽 |
| 厨房面积 | ≥ **6.0 ㎡** | **燃柴灶宜 ≥10 ㎡**（农村实际） |
| 入口过道净宽 | ≥ **1.20 m** | |
| 其他过道净宽 | ≥ **1.00 m** | 以厅代廊时，厅即过道，须满足此宽 |
| 梯段净宽 | 两侧有墙 ≥ **0.90 m**；一侧临空 ≥1.00 m | |
| 踏步 | 宽 ≥ **0.22 m**，高 ≤ **0.20 m** | 层高 3.9 m 时约 23 级 |
| 栏杆 / 女儿墙 | 高 ≥ **1.05 m**，杆件净距 ≤ **0.11 m** | 实体砌体优于铁艺（湿热环境锈蚀快） |
| 窗台 | < **0.90 m** 需防护 | |
| 窗地比 | ≥ **1/7** | |
| 通风开口 | ≥ **地面面积 5%** | |
| 堂屋 | 居中轴、≥ **10 ㎡** | 红白事主厅 |
| 开间 | ≤ **6 m** | 单面采光进深 ≤6 m |

## 三、布置禁忌

| # | 禁忌 | 说明 |
|---|---|---|
| 1 | **楼层卫生间不得布置在卧室、堂屋、厨房、餐厅正上方** | 审图必看。解法：卫生间各层**竖向对齐**，立管一根到底 |
| 2 | 柴草 / 农具房宜独立或做**防火墙分隔** | 并入主体时必须分隔 |
| 3 | 老人房应取**日照最优朝向** | 西墙朝南偏东者日照最好，开大窗 |
| 4 | 东侧山墙贴邻时**不开窗**、做**不燃实体墙** | 防火与隐私双重要求 |
| 5 | 神位（家神位）须**背实墙**、居中轴、正对入户门 | 不得悬空；独立神龛属"家具"可搬走，贴墙神台属"构造"搬不走 |

## 四、间距与防火

| 项 | 要求 |
|---|---|
| 前后间距与建筑高度比 | 不低于 **1 : 1** |
| 相邻房屋山墙间距 | ≥ **4 m** |
| 防火间距（GB 50039） | 一、二级耐火 **≥4 m**；三、四级 **≥6 m** |
| 后退支路红线 | ≥ **1 m** |
| 后退干路红线 | ≥ **3 m** |
| 朝向 | 宜朝南或**南偏东 / 南偏西** |

---

## 五、抗震与结构（须专业深化）

| 区域 | 抗震设防 | 设计地震分组 |
|---|---|---|
| 福建漳州（龙海） | **7 度，0.15 g** | 第二组 |

> 本项目位于抗震设防区，须按 GB 50011 做抗震设计；
> 三层住宅宜采用框架结构或抗震墙结构，不得用纯砖砌体承重。

## 六、报建与设计资质

| # | 事项 |
|---|---|
| 1 | 施工图**须由有资质单位或注册执业人员设计**，或选用省级通用图（办法第二十七条） |
| 2 | **4 层及以上须由有资质施工企业施工**（第二十八条） |
| 3 | 规划方案**不能直接用于报建**，只能作为业主评审与后续深化依据 |
| 4 | 涉河构筑物（跨河小桥、护岸）须另行**报水利部门** |
| 5 | 红线外用地（前院、缺角院子）须与**村集体、邻户**确认使用权，最好签协议 |
| 6 | 原址重建须先明确**原建筑拆除范围** |

## 八、快速自检清单（出方案前逐条打勾）

- [ ] 已向乡镇审批窗口核实**建筑面积上限**（省级 300 ㎡，取得书面依据）
- [ ] 已向自然资源部门核实**限高**（常见 12 m / 15 m）
- [ ] 层数 ≤ 3（或已确认本地可放宽）
- [ ] 计容建筑面积 ≤ 上限；**两个口径都算过**（规范计容 / 实际覆盖）
- [ ] 基底 / 红线 ≤ 80%（或已确认本地执行值）
- [ ] 各层层高在 3 m 左右（超标项已单独说明）
- [ ] 总高 ≤ 14 m（含坡屋顶）
- [ ] **卫生间各层竖向对齐**，无卫生间隔层压卧室
- [ ] 老人房取了最优朝向
- [ ] 过道 / 梯段 / 踏步 / 栏杆尺寸逐项合规
- [ ] 山墙间距与防火间距满足
- [ ] **小河洪水位已实测**（一层地坪标高完全取决于此）
- [ ] 红线外用地的使用关系已落实（书面）
- [ ] 拆除范围已明确
- [ ] 已向业主说明：施工图须另由有资质单位出具
