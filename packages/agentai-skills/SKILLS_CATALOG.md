## 📝 技能贡献指南

每个技能包含一个 `SKILL.md` 文件, 格式:
```yaml
---
name: skill-name
description: 中文 / English
metadata:
  category: 行业
  tags: [标签]
  parallelSafe: boolean
  riskLevel: low/medium/high
  triggers: [自动触发关键词]
---
```

+ Markdown 文档说明

新增技能后:
1. 放在对应类别目录
2. 更新本文件索引
3. 重启 Gateway 自动加载
