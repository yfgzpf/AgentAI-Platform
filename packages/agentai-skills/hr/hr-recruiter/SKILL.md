# HR 全流程助手 👥

专业的 HR 全流程工具, 覆盖招聘 / 培训 / 绩效 / 薪酬 / 员工关系。

## 核心功能

### 1. 招聘 JD 撰写

**JD 模板**:
```
【职位名称】高级前端工程师
【工作地点】北京 / 远程
【薪资范围】25K-50K × 14 薪
【经验要求】3-5 年
【学历要求】本科及以上
【岗位职责】
1. 负责 XXX 业务前端开发
2. 参与架构设计与技术选型
3. 推动工程效率提升
4. 带教初中级工程师
【任职要求】
1. 计算机相关专业, 3 年以上经验
2. 精通 React/Vue, 理解原理
3. 有大型项目经验
4. 良好的工程素养
【加分项】
- 开源项目贡献
- 技术博客 / 演讲
- 跨端开发经验
```

**JD 关键词**:
- 必备: 硬技能 + 经验 + 学历
- 加分: 软技能 + 文化契合
- 福利: 弹性 / 培训 / 股权
- 团队: 规模 / 背景 / 文化

### 2. 简历筛选

**评估维度**:

| 维度 | 权重 | 评估 |
|------|------|------|
| 学历 | 10% | 985/211 > 一本 > 二本 > 专科 |
| 公司背景 | 20% | BAT/TMD > 独角兽 > 上市公司 > 普通公司 |
| 项目经验 | 30% | 复杂度 + 影响力 + 个人贡献 |
| 技术深度 | 25% | 主流技术 + 原理理解 |
| 稳定性 | 10% | 跳槽频率 + 行业连续性 |
| 软技能 | 5% | 沟通 / 团队 / 学习 |

**STAR 法则评估项目**:
- **S**ituation: 背景
- **T**ask: 任务
- **A**ction: 行动
- **R**esult: 结果 (量化)

**红牌信号** 🚩:
- 频繁跳槽 (1 年 1 跳)
- 简历夸大 / 与职位不匹配
- 项目描述空泛 (无数据)
- 离职原因模糊
- 期望薪资过高

**绿牌信号** ✅:
- 行业连续性
- 渐进式成长
- 量化成果
- 开源 / 博客 / 演讲
- 推荐人

### 3. 面试题库

#### 行为面试 (Behavior)

**高频问题**:
```
1. 请介绍一个你最有成就感的项目
2. 遇到的最大技术挑战是什么? 如何解决?
3. 跟同事 / 上级有分歧时怎么处理的?
4. 你 5 年后的职业规划?
5. 为什么离开上一家公司?
6. 你的优缺点?
7. 你最崇拜的技术人? 学到什么?
8. 团队协作中, 你承担什么角色?
9. 压力最大的一次经历?
10. 你能为团队带来什么独特价值?
```

**STAR 评估**:
```
S (背景): 清晰? 5 分
T (任务): 明确? 5 分
A (行动): 具体? 5 分
R (结果): 量化? 5 分
总分 / 20
```

#### 技术面试 (Technical)

**算法题 (校招 / 社招初级)**:
- 数组 / 链表 / 栈 / 队列
- 二叉树 / 图
- 动态规划
- 贪心 / 二分
- LeetCode Easy/Medium

**系统设计 (高级 / 架构)**:
- 短链生成器
- 微博 / 朋友圈
- 网约车派单
- 秒杀系统
- 分布式限流
- 消息队列
- 搜索引擎

**编码能力**:
- 现场编码
- 代码审查
- 调试能力
- 测试思维

**架构能力**:
- 微服务 vs 单体
- CAP / BASE
- 一致性哈希
- 分布式锁
- 消息可靠性

#### 压力面试 (Stress)

**常见刁难**:
- "你这道题没做出来, 怎么说?"
- "你之前的项目也没什么难的嘛"
- "你的能力似乎达不到我们要求"
- "你觉得你比其他人强在哪?"

**应对**:
```
1. 不辩解, 承认不足
2. 展示学习能力
3. 用案例证明
4. 保持冷静
```

### 4. 薪酬设计

**薪酬结构**:
```
总薪酬 = 基本工资 + 绩效工资 + 津贴 + 福利 + 长期激励
```

| 项目 | 占比 | 说明 |
|------|------|------|
| 基本工资 | 60-70% | 月度发放, 保障 |
| 绩效工资 | 10-20% | 与业绩挂钩 |
| 津贴 | 5-10% | 通讯/交通/餐补 |
| 福利 | 5-10% | 社保/公积金/商业保险 |
| 长期激励 | 5-20% | 股票/期权 |

**薪酬带宽**:
```
P25 (入门级) - P50 (市场) - P75 (优秀) - P90 (顶级)
例: 25K - 35K - 50K - 70K
```

**薪酬调研**:
- Levels.fyi (互联网)
- 薪智 / 薪酬网
- 猎聘 / Boss 直聘
- 行业报告 (韦莱韬悦 / 美世)

**股权激励**:
- 期权 (Option): 行权价
- 限制性股票 (RSU): 直接授予
- 虚拟股 (Phantom): 现金结算
- 员工持股 (ESOP)

### 5. 绩效评估

**KPI 设计 (SMART)**:
- **S**pecific: 具体
- **M**easurable: 可衡量
- **A**chievable: 可达成
- **R**elevant: 相关
- **T**ime-bound: 时限

**OKR 方法**:
```
O (目标): 提升用户活跃度
  KR1: DAU 从 100 万 → 150 万
  KR2: 留存率从 40% → 50%
  KR3: 用户日均使用时长从 20 分钟 → 30 分钟
```

**360° 评估**:
- 上级 (权重 40%)
- 平级 (权重 30%)
- 下级 (权重 15%)
- 客户 (权重 15%)

**绩效等级** (强制分布):
| 等级 | 比例 | 描述 |
|------|------|------|
| S | 5-10% | 卓越 |
| A | 20-30% | 优秀 |
| B | 40-60% | 合格 |
| C | 10-15% | 待改进 |
| D | 5% | 不合格 |

**绩效面谈 (GROW 模型)**:
- G (Goal): 目标
- R (Reality): 现状
- O (Options): 选项
- W (Will): 意愿

### 6. 员工关系

**入离职流程**:

**入职**:
```
1. 背景调查 (Offer 前)
2. Offer 发放
3. 体检
4. 签订合同
5. 社保公积金转入
6. 工位 / 设备准备
7. 入职培训
8. 导师分配
9. 试用期 (1-6 月)
```

**离职**:
```
1. 员工提出 (提前 30 天)
2. 离职面谈
3. 工作交接 (14 天)
4. 资产归还
5. 工资结算 (N / N+1)
6. 社保转移
7. 离职证明
8. 知识沉淀 (文档)
9. 欢送 / 校友会
```

**劳动法关键点**:

| 情形 | 赔偿 |
|------|------|
| 违法解除 | 2N |
| 协商解除 | N |
| 经济性裁员 | N + 代通知金 |
| 合同到期不续签 | N (公司原因) |
| 试用期不符合 | 随时 (需证明) |
| 员工主动离职 | 0 |
| 严重违纪 | 0 (需制度依据) |

N = 工作年限 × 月工资 (满半年算 1, 不满半年算 0.5)

### 7. 培训发展

**新员工培训**:
- Day 1: 入职手续 + 部门介绍
- Week 1: 公司文化 + 制度
- Month 1: 业务培训 + 导师带教
- Month 3: 转正答辩

**培训方法**:
- 课堂讲授
- 案例研讨
- 角色扮演
- 在岗实训
- 导师制
- 行动学习

**学习地图 (技术岗)**:
```
P3 (初级) → P4 (中级) → P5 (高级) → P6 (资深) → P7 (专家) → P8 (首席)
```

### 8. 组织发展

**岗位评估 (海氏法)**:
- 知识技能
- 解决问题
- 承担责任

**职级体系 (阿里 P 序列)**:
- P4: 专员
- P5: 高级专员
- P6: 经理
- P7: 高级经理 / 资深
- P8: 总监
- P9: 高级总监
- P10: VP
- P11: 高级 VP
- P12: 总裁

**晋升答辩**:
1. 自评 + 述职
2. 项目展示
3. 技术分享
4. 评委提问
5. 投票 (HR + 上级 + 跨级)
6. 结果反馈

## 注意事项

⚠️ **法律红线**: 不符合劳动法会引发仲裁
⚠️ **公平公正**: 避免歧视 (性别/年龄/地域)

⚠️ **员工体验**: 离职面谈保持尊重
⚠️ **保密意识**: 薪酬 / 绩效信息保密
