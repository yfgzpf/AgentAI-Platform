专业的菜谱、餐饮开店、营养计算、菜单设计、外卖运营工具。

## 核心功能

### 1. 菜谱生成

**输入**:
```
- 菜系: 川菜 / 粤菜 / 西餐 / 日料
- 难度: 简单 / 中等 / 高级
- 时间: < 30 分钟
- 主要食材: 鸡 / 鱼 / 蔬菜
- 口味: 麻辣 / 酸甜 / 咸鲜
- 人数: 2-3 人
```

**菜谱模板**:
```markdown
# 麻婆豆腐 (4 人份)

## 食材
- 主料:
  - 嫩豆腐 500g
  - 牛肉末 100g (或猪肉末)
- 辅料:
  - 郫县豆瓣酱 2 汤匙
  - 豆豉 1 茶匙
  - 蒜末 1 汤匙
  - 姜末 1 茶匙
  - 葱花 适量
- 调料:
  - 生抽 1 汤匙
  - 料酒 1 汤匙
  - 花椒粉 1 茶匙
  - 辣椒粉 1 茶匙
  - 糖 1 茶匙
  - 水淀粉 适量
  - 食用油 3 汤匙
  - 高汤 200ml

## 步骤
1. 豆腐切 2cm 方丁, 焯水 (加盐) 备用
2. 热锅下油, 爆香姜蒜末
3. 下牛肉末煸炒至变色
4. 加豆瓣酱, 豆豉炒出红油
5. 加高汤, 生抽, 料酒, 糖
6. 下豆腐, 小火煮 5 分钟
7. 勾芡 (分 3 次, 每次少量)
8. 撒花椒粉, 葱花
9. 完成!

## 关键技巧
- 豆腐焯水: 加盐去豆腥, 保形
- 牛肉末: 煸香是关键
- 勾芡: 分次, 红亮不浑汤
- 花椒粉: 增香, 最后放

## 营养 (每份)
- 热量: 280 kcal
- 蛋白: 18g
- 脂肪: 16g
- 碳水: 12g
- 钠: 980mg

## 难度 ⭐⭐
## 时间 25 分钟
```

### 3. 营养计算

**基础计算**:
```
BMR (基础代谢) Mifflin-St Jeor:
- 男: 10×体重 + 6.25×身高 - 5×年龄 + 5
- 女: 10×体重 + 6.25×身高 - 5×年龄 - 161

TDEE (每日消耗) = BMR × 活动系数
- 久坐: 1.2
- 轻度: 1.375
- 中度: 1.55
- 高度: 1.725

减脂: TDEE - 500 kcal
增肌: TDEE + 300 kcal
```

**宏量营养素** (克/天):
| 目标 | 蛋白 | 脂肪 | 碳水 |
|------|------|------|------|

| 维持 | 1.2-1.5g/kg | 0.8g/kg | 3-5g/kg |

### 4. 餐饮开店

**开店流程**:
```
1. 市场调研
   - 选址: 人流 / 竞品 / 消费力
   - 定位: 客群 / 价位 / 风格
   - 差异化: 卖点 / 特色

2. 商业计划
   - 投资: 租金 + 装修 + 设备 + 原料
   - 营收预测: 翻台率 × 客单价 × 桌数
   - 盈亏平衡: 月成本 / 客单价
   - 投资回收: 总投资 / 月净利

3. 证照办理
   - 营业执照
   - 食品经营许可证
   - 餐饮服务许可证
   - 消防 / 卫生 / 环保

4. 装修设计
   - 前厅: 动线 / 灯光 / 氛围
   - 后厨: 出餐效率 / 安全 / 卫生

5. 设备采购
   - 灶具 / 油烟机
   - 冷柜 / 冰柜
   - 消毒柜
   - POS 系统

6. 员工招聘培训
   - 厨师 / 服务员
   - 收银 / 领班

7. 试营业
   - 流程打磨
   - 菜单调整
   - 员工磨合

8. 正式营业
   - 营销推广
   - 客户积累
```

**成本结构** (典型餐饮):
```
租金: 25-30%
人工: 25-30%
原料: 30-35%
能耗: 3-5%
其他: 5-10%
净利率: 5-15%
```

**选址关键指标**:
- 人流量 (工作日 / 周末)
- 客流画像 (年龄 / 消费)
- 可见度 (门口 / 招牌)
- 到达便利 (停车 / 公交 / 地铁)
- 竞品密度
- 租金可承受

**菜单设计** (Menu Engineering):
| 类型 | 特征 | 策略 |
|------|------|------|
| 🌟 明星 | 高销量 + 高利润 | 主推, 突出位置 |
| 🐎 摇钱树 | 低销量 + 高利润 | 推高销量 |
| 🐄 耕牛 | 高销量 + 低利润 | 提价, 控成本 |
| 🐕 瘦狗 | 低销量 + 低利润 | 淘汰 |

**定价方法**:
- 成本加成 (30-50%)
- 市场参考 (跟随)
- 价值定价 (感知价值)
- 心理定价 (99 / 199)
- 锚定定价 (高低搭配)

### 6. 厨房技巧

**刀工**:
- 直刀切: 丝 / 丁 / 片
- 推刀切: 薄片
- 拉刀切: 韧性
- 锯刀切: 面包

**火候**:

- 中火: 烧 / 烩
- 小火: 炖 / 煨 / 焖

**调味**:
- 基本味: 咸 / 酸 / 甜 / 辣 / 鲜 / 苦
- 复合味: 鱼香 / 宫保 / 麻辣
- 平衡: 对比 / 互补

**食材处理**:
- 焯水: 去腥 / 保持色泽
- 滑油: 嫩肉
- 腌制: 入味 / 嫩肉
- 上浆: 嫩肉
- 挂糊: 外脆里嫩

### 7. 食品安全

**储存温度**:
| 类别 | 温度 | 时间 |
|------|------|------|
| 冷藏 | 0-4°C | 1-3 天 |
| 冷冻 | -18°C | 3-12 月 |
| 常温 | 阴凉干燥 | 看标签 |

**生熟分开**:
- 不同砧板
- 不同刀具
- 不同储存
- 不同手套

**彻底加热**:
- 中心温度 > 75°C
- 现做现吃
- 不反复加热

**过期识别**:
- 看日期
- 看外观
- 闻气味
- 看质地

## 注意事项

⚠️ **食品安全第一**: 不吃过期变质
⚠️ **过敏源**: 提前询问 (坚果 / 海鲜)
⚠️ **营养均衡**: 多样化, 不偏食
⚠️ **适量原则**: 再好吃也不过量
⚠️ **卫生习惯**: 勤洗手, 生熟分开
⚠️ **新鲜优先**: 少吃加工食品
⚠️ **特殊人群**: 老人 / 孕妇 / 儿童 / 慢病
⚠️ **餐饮卫生**: 持证经营, 定期体检
