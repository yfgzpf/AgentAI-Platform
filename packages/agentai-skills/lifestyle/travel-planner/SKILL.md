# 旅游规划师 ✈️

专业的旅行规划、行程定制、签证、攻略工具。

## 核心功能

### 1. 行程定制

**输入信息**:
```
- 目的地: 日本 / 泰国 / 欧洲
- 时间: 出发日期 + 天数
- 人数: 成人 + 儿童
- 预算: 总预算 / 人均
- 偏好: 自然 / 文化 / 美食 / 购物 / 亲子
- 节奏: 紧凑 / 舒适 / 慵懒
```

**输出模板**:
```
# 京都 5 日深度游

## Day 1: 抵达 + 市区
- 09:00 抵达成田机场
- 12:00 入住酒店 (京都站)
- 14:00 清水寺 + 二年坂三年坂
- 18:00 祇园 + 花见小路
- 19:30 怀石料理晚餐

## Day 2: 岚山 + 金阁寺
- 08:00 嵯峨野小火车
- 12:00 岚山豆腐料理
- 14:00 金阁寺
- 16:00 北野天满宫
- 18:00 锦市场小吃

...

## 预算
| 项目 | 金额 (RMB) |
|------|------------|
| 机票 | 4000 |
| 酒店 (4 晚) | 3000 |
| 餐饮 | 1500 |

| **合计** | **12300** |
```

### 2. 机票预订

**便宜机票技巧**:
- 🕐 提前 1-3 个月
- 📅 周二 / 周三最便宜
- 🛫 凌晨 / 深夜航班便宜
- 🔍 比价: Google Flights / Skyscanner / 携程
- 🛬 中转比直飞便宜
- 🌐 VPN 看当地价格
- 🧳 不带行李最便宜
- 📱 关注航司促销 (亚航 0 元大促)

**价格日历**:
```
        Mon Tue Wed Thu Fri Sat Sun
1月 1   800 700 700 900 1200 1300 1100
1月 8   900 750 750 950 1300 1400 1200
```

**里程积分**:
- 航空联盟: 星空 / 天合 / 寰宇一家
- 信用卡积分兑换
- 家庭账户累计
- 升舱技巧

### 3. 酒店选择

**平台对比**:
| 平台 | 特点 |
|------|------|
| Booking | 全球, 取消灵活 |
| Agoda | 亚洲, 经常便宜 |
| Airbnb | 民宿, 长住 |
| 携程 | 国内, 客服好 |
| Trip.com | 中文友好, 国际 |
| Hotels.com | 10 晚送 1 晚 |
| Google Hotels | 中性搜索 |

**酒店类型**:
- 🏨 商务酒店 (中端, 标准化)
- 🏩 度假酒店 (高端, 设施多)
- 🏠 民宿 (体验本地生活)
- 🛏️ 青旅 (便宜, 社交)
- 🏢 服务式公寓 (长住首选)

**位置选择**:
- 市中心 (景点近, 贵)
- 交通枢纽 (地铁站旁, 方便)
- 郊区 (便宜, 需通勤)
- 本地社区 (体验生活)

**评分参考**:
- 8.0+ 不错
- 8.5+ 推荐
- 9.0+ 卓越
- 看差评比看好评重要

**热门签证**:

### 7. 行李清单

**通用**:
```
📄 证件: 护照 / 身份证 / 驾照 / 复印件
💳 资金: 信用卡 (2 张) / 现金 / 借记卡
📱 电子: 手机 / 充电器 / 充电宝 / 转换插头
🧴 洗漱: 牙刷 / 牙膏 / 洗发水 (小样) / 防晒
👕 衣物: T恤 / 内衣 / 袜子 / 睡衣
🧥 鞋帽: 运动鞋 / 拖鞋 / 帽子
💊 药品: 感冒 / 肠胃 / 创可贴 / 个人药
🧳 其他: 水杯 / 雨伞 / 墨镜 / 颈枕
```

**飞行液体限制** (国际):
- 每瓶 ≤ 100ml
- 装入 1L 透明袋
- 1 人 1 袋

**托运 / 随身**:
- 托运: 重物 / 易碎 / 备用
- 随身: 贵重 / 重要 / 液体
- 锂电池只能随身 (不能托运)

### 8. 应急处理

**护照丢失**:
```
1. 报警 (警察局开报失证明)
2. 中国大使馆办旅行证
3. 回国后补办护照
```

**生病**:
```
- 保险: 买境外医疗险
- 医院: 大使馆推荐
- 药: 自备常用药
- 翻译: 找华人医生 / 翻译
```

**信用卡被盗**:
```
1. 立即挂失 (客服电话)
2. 报警
3. 申请新卡
4. 争议账单
```

**手机丢失**:
```
1. 远程锁定 (iCloud / Find My Device)
2. 运营商挂失 SIM
3. 重要账户改密
4. 补卡 / 备用机
```

**大使馆联系方式**:
- 外交部 12308
- 各驻外使馆 24h 电话

## 注意事项

⚠️ **签证时效**: 出行前 1-3 月申请
⚠️ **保险必备**: 医疗 + 行李 + 航班
⚠️ **应急现金**: 备用 USD 200-500
⚠️ **重要备份**: 证件 + 照片备份
⚠️ **当地法律**: 了解禁忌 (如新加坡口香糖)
⚠️ **时差调整**: 出发前 1 周调整作息
⚠️ **网络准备**: 漫游 / 当地卡 / VPN
⚠️ **小费文化**: 了解当地习惯
