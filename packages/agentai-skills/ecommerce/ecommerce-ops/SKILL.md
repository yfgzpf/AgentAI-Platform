## 核心功能

### 1. 选品分析

**选品框架**:
```
1. 市场规模 (TAM/SAM/SOM)
2. 增长率 (近 3 年 CAGR)
3. 竞争强度 (竞品数量 / 头部集中度)
4. 利润空间 (毛利率 / 净利率)
5. 供应链 (可获取性 / 稳定性)
6. 物流友好 (体积 / 重量 / 易碎)
7. 合规风险 (专利 / 认证 / 平台规则)
```

**数据来源**:
- 平台生意参谋 (淘宝/天猫)
- 京东商智
- 蝉妈妈 (抖音)
- 亚马逊 BSR / Helium 10 / Jungle Scout
- Google Trends
- 5118 / 飞瓜

**选品工具**:
- 1688 / 义乌购 (找货)
- 拼多多 (比价)
- 阿里指数
- 百度指数
- 微信指数

### 2. Listing 优化

**标题公式** (亚马逊 A9 算法):
```
[品牌] + [核心关键词] + [属性词] + [使用场景] + [容量/数量]
例: Anker PowerCore 10000 Portable Charger 10000mAh Power Bank for iPhone
```

**五点描述 (Bullet Points)**:
```
1. 主要卖点 + 核心规格
2. 次要卖点 + 优势对比
3. 适用场景 + 目标用户
4. 售后保障 + 服务承诺
5. 包装清单 + 赠品信息
```

**A+ 页面**:
- 高清场景图
- 对比图 (vs 竞品)
- 信息图表
- 品牌故事
- 视频

**关键词策略**:
- 核心词 (Head Term)
- 长尾词 (Long-tail)
- 互补词 (Complementary)
- 季节性词
- 品牌词 (注意侵权)

### 3. 广告投放

**亚马逊 PPC**:
| 类型 | 用途 | 建议预算 |
|------|------|----------|
| Sponsored Products | 推单品 | 主力 70% |
| Sponsored Brands | 推品牌 | 20% |
| Sponsored Display | 再营销 | 10% |

**关键词匹配**:
- 精准 (Exact): 高转化
- 词组 (Phrase): 平衡
- 广泛 (Broad): 拓流量

**ACOS 健康**:
- 新品期: ACOS < 50% (亏损换排名)
- 成长期: ACOS < 30%
- 成熟期: ACOS < 20%

**淘宝直通车**:
- 关键词出价
- 智能词包
- 定向 (人群 / 场景)
- 创意 (文案 / 主图)

**抖音千川**:
- 短视频带货
- 直播带货
- 巨量引擎

### 4. 客服话术

**开场白**:
```
亲, 您好! 很高兴为您服务~
有什么可以帮到您的吗?
```

**常见问题应对**:

| 问题 | 应对 |
|------|------|
| 什么时候发货 | 24 小时内, 默认顺丰 |
| 几天到货 | 江浙沪 1-2 天, 其他 3-5 天 |
| 可以便宜吗 | 已经是最优惠了, 送您小礼品 |
| 质量怎么样 | 7 天无理由, 一年质保 |
| 尺码怎么选 | 建议您测量 XX, 看尺码表 |
| 跟图片一样吗 | 实物拍摄, 略有色差正常 |

**差评回复模板**:
```
亲, 非常抱歉给您带来不好的体验 🙏
关于 [具体问题], 我们会立即核实处理
您的反馈已记录, 我们会持续改进
如需 [退换 / 补偿], 请联系客服优先处理
```

**中差评处理流程**:
1. 24 小时内回复
2. 私下联系解决
3. 提供方案 (退款 / 补发 / 补偿)
4. 邀请修改评价
5. 严重问题升级

### 5. 退货退款

**退货原因分析**:
| 原因 | 占比 | 处理 |
|------|------|------|
| 不喜欢 / 不合适 | 40% | 协商部分退款 |
| 质量问题 | 25% | 优先退款 + 道歉 |
| 与描述不符 | 15% | 全额退款 + 改进 |
| 物流问题 | 10% | 补发 / 退款 |
| 卖家发错 | 5% | 补发 + 赠品 |
| 其他 | 5% | 视情况 |

**退款话术**:
```
亲, 已经为您办理退款, 款项会在 1-3 个工作日退回原支付账户
商品麻烦您寄回, 运费我们承担 (质量问题)
感谢您的理解与支持 ❤
```

### 6. 竞品监控

**监控维度**:
- 价格变动
- 销量 / 排名
- 评价 (数量 / 评分 / 内容)
- 主图 / 视频 / 详情
- 广告投放
- 新品上架

**工具**:
- 生意参谋 (竞品分析)
- 蝉妈妈 (抖音)
- Helium 10 (亚马逊)
- 卖家精灵

**定价策略**:
- 渗透定价 (低价抢量)
- 撇脂定价 (高价高利)
- 价格跟随 (随大流)
- 锚定定价 (对比衬托)
- 心理定价 (99 / 199)

### 7. 数据分析

**核心指标**:

| 指标 | 公式 | 健康值 |
|------|------|--------|
| UV 价值 | 销售额 / UV | > 1 |
| 转化率 | 下单数 / UV | > 2% |
| 客单价 | 销售额 / 订单数 | 提升 |
| 复购率 | 复购客户 / 总客户 | > 30% |
| 好评率 | 好评 / 总评 | > 98% |
| 退货率 | 退货 / 销售 | < 10% |
| ROI | 销售 / 广告 | > 3 |
| CTR | 点击 / 展现 | > 2% |

**流量结构**:
- 免费流量 (搜索 / 推荐): 主力 50%+
- 付费流量 (直通车 / 钻展): 30%
- 私域流量 (粉丝 / 群): 20%

**转化漏斗**:
```
展现 → 点击 → 加购 → 下单 → 付款 → 收货 → 复购
100%    5%    30%    20%    18%    95%    30%
```

## 注意事项

⚠️ **平台规则**: 各平台规则不同, 注意合规
⚠️ **广告风险**: 误操作可能烧钱, 小步快跑
⚠️ **库存管理**: 滞销占资金, 断货失排名
⚠️ **资金链**: 备货 / 广告 / 物流都是钱
⚠️ **品牌建设**: 长期主义, 不要纯打价格战
