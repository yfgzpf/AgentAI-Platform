# 财务分析师 💼

专业的财务报表分析、估值建模工具，覆盖三大报表 + 估值方法。

## 核心功能

### 1. 三大报表分析

**资产负债表 (Balance Sheet)**
- 资产 / 负债 / 权益结构
- 流动比率 / 速动比率 / 现金比率
- 资产负债率 / 权益乘数
- 周转率 (应收 / 存货 / 总资产)

**利润表 (Income Statement)**
- 收入 / 成本 / 毛利
- 三费 (销售/管理/研发)
- 经营利润 / 净利润
- EPS / 每股净资产
- 同比 / 环比

**现金流量表 (Cash Flow Statement)**
- 经营 / 投资 / 筹资 三类现金流
- 自由现金流 FCF = OCF - CapEx
- 资本支出 / 分红 / 回购

### 2. 估值方法

**DCF 估值 (Discounted Cash Flow)**
```python
{
  "wacc": 0.10,           # 加权平均资本成本
  "terminal_growth": 0.03, # 永续增长率
  "forecast_years": 5,     # 显式预测期
  "fcf_year1": 1_000_000,  # 第一年自由现金流
  "growth_rates": [0.15, 0.12, 0.10, 0.08, 0.05],  # 5 年增长率
}
```

**相对估值 (Comparables)**
- PE / PB / PS / EV/EBITDA / EV/Sales
- 同行业可比公司中位数 / 平均数
- PEG (考虑增长)

**DDM 估值 (Dividend Discount Model)**
- 适用于稳定分红的公司

**NAV 估值 (Net Asset Value)**
- 适用于重资产 / 房地产 / 金融

**剩余收益模型 (RIM)**
- 适用于 ROE 稳定的公司

### 3. 杜邦分析 (DuPont)

```
ROE = 净利率 × 总资产周转率 × 权益乘数
   = (Net Income / Sales) × (Sales / Assets) × (Assets / Equity)
```

**示例分解**:
```
ROE 提升路径:
- 提升净利率 (提价 / 降成本)
- 提升周转率 (优化库存 / 应收)
- 提升杠杆 (借债经营, 但增加风险)
```

### 4. 财务预警

**Z-Score 模型** (破产预警)
```
Z = 1.2*A + 1.4*B + 3.3*C + 0.6*D + 1.0*E
A = 营运资金 / 总资产
B = 留存收益 / 总资产
C = EBIT / 总资产
D = 股权市值 / 负债账面
E = 销售收入 / 总资产

Z > 2.99 安全
1.81 < Z < 2.99 灰色
Z < 1.81 危险
```

**Beneish M-Score** (盈利操纵预警)
- 8 个指标, > -1.78 警惕

## 财务比率速查

### 盈利能力
| 指标 | 公式 | 健康值 |
|------|------|--------|
| 毛利率 | (营收-成本)/营收 | > 30% |
| 净利率 | 净利润/营收 | > 10% |
| ROE | 净利润/平均权益 | > 15% |
| ROA | 净利润/平均资产 | > 7% |
| ROIC | NOPAT/投入资本 | > WACC |

### 偿债能力
| 指标 | 公式 | 健康值 |
|------|------|--------|
| 流动比率 | 流动资产/流动负债 | > 2 |
| 速动比率 | (流动资产-存货)/流动负债 | > 1 |
| 资产负债率 | 负债/资产 | < 70% |
| 利息保障倍数 | EBIT/利息支出 | > 3 |

### 运营能力
| 指标 | 公式 | 越快越好 |
|------|------|----------|
| 应收账款周转 | 营收/平均应收 | 高 |
| 存货周转 | 成本/平均存货 | 高 |
| 总资产周转 | 营收/平均总资产 | 高 |

### 成长能力
| 指标 | 公式 | 健康值 |
|------|------|--------|
| 收入增长率 | (本期-上期)/上期 | > 行业均值 |
| 净利润增长率 | 同上 | > 收入增速 |
| 自由现金流增长率 | 同上 | > 10% |

## 估值报告模板

```markdown
# 600519 贵州茅台 估值分析

## 1. 核心数据
- 当前股价: 1680.00
- 总股本: 12.56 亿
- 总市值: 21,101 亿
- 52 周高/低: 1890 / 1380
- PE (TTM): 27.5
- PB: 9.8
- 股息率: 1.4%

## 2. 财务表现
| 指标 | 2021 | 2022 | 2023 | 2024E |
|------|------|------|------|-------|
| 营收(亿) | 1094 | 1241 | 1505 | 1730 |
| 净利润(亿) | 524 | 627 | 747 | 870 |
| 毛利率 | 91.5% | 91.9% | 92.1% | 92.3% |
| ROE | 30% | 32% | 33% | 33% |
| FCF(亿) | 480 | 580 | 690 | 800 |

## 3. 估值结论
- DCF 内在价值: 1850 元
- 相对估值 (PE 30x): 1820 元
- 综合目标价: 1835 元
- 当前价格 1680 元, 上行空间 9.2%
- 评级: 持有
```

## 注意事项

⚠️ **财报粉饰**: 关注非经常性损益, 调整后利润
⚠️ **会计政策**: 不同公司会计政策差异 (如收入确认)
⚠️ **季节性**: 季度数据要年化或对比同期
⚠️ **非财务因素**: 行业政策、竞争格局、管理层
⚠️ **估值假设**: DCF 对 WACC 和 g 极度敏感
