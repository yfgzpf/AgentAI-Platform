# AgentAI Gateway Logo

## Logo 设计方案

### 方案 A — 枢纽门户 🔵
- **颜色**: 深蓝色 (#1a3a5c) + 电光青色 (#00d4ff)
- **概念**: 门形拱桥融入电路线条，代表多智能体汇聚的中枢
- **适用**: 官网首页、技术文档

### 方案 B — 极简网关 🟣
- **颜色**: 紫青渐变 (#4a2d8a → #00e5ff)
- **概念**: 六边形内含连接节点，简洁专业
- **适用**: 开发者工具、npm 包图标

### 方案 C — 神经之门 🟡
- **颜色**: 霓虹风格 (cyan + magenta)
- **概念**: 字母"A"变形为网关，内部神经网络发光
- **适用**: 品牌宣传、社交媒体

## 使用规范

- 最小尺寸: 32x32px
- 背景: 深色背景推荐方案 A/C，浅色背景推荐方案 B
- 格式: PNG (透明背景) / SVG (矢量)
