# 中医医案知识库

## 目录结构

| 文件 | 内容 |
|------|------|
| `famous_cases.jsonl` | 名老中医经典医案 (叶天士/张锡纯/刘渡舟等) |
| `syndrome_cases.jsonl` | 按证型分类的医案索引 |

## JSONL 条目格式

```json
{
  "id": "CASE-001",
  "doctor": "叶天士",
  "era": "清代",
  "chief_complaint": "咳嗽三月，痰多色白",
  "symptoms": ["咳嗽", "痰多色白", "胸闷", "纳差"],
  "tongue": "舌淡红，苔白腻",
  "pulse": "脉滑",
  "syndrome": "痰湿蕴肺证",
  "treatment": "燥湿化痰，理气止咳",
  "formula": "二陈汤加减",
  "herbs": [
    {"name": "半夏", "dose": "9g", "role": "君"},
    {"name": "陈皮", "dose": "6g", "role": "臣"},
    {"name": "茯苓", "剂量": "12g", "role": "佐"},
    {"name": "甘草", "dose": "3g", "role": "使"}
  ],
  "outcome": "服药五剂，咳减痰少，续服七剂而愈",
  "analysis": "脾为生痰之源，肺为贮痰之器。治当燥湿健脾，杜绝生痰之源。"
}
```

## 使用方式

由 `tcm_case` 子智能体通过症状/证型匹配相似案例。
匹配维度: 症状相似度 + 证型一致性 + 用药关联性。

## 数据来源

- 《临证指南医案》— 叶天士
- 《医学衷中参西录》— 张锡纯
- 后续: zy-agent 项目医案库迁移
