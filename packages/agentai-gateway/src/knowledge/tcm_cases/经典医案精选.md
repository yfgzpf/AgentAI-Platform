# 经典中医医案精选

## 医案一: 肝郁脾虚型胃痛 (叶天士风格)

**患者**: 女, 35岁
**主诉**: 胃脘胀痛半年, 情志不畅时加重

**症状详情**:
- 胃脘胀满隐痛, 连及两胁
- 嗳气频作, 善太息
- 纳差, 食后胀甚
- 大便溏薄, 日行1-2次
- 月经不调, 经前乳胀
- 舌淡红, 苔薄白, 脉弦细

**辨证分析**:
- 病位: 肝(主疏泄) + 脾(主运化)
- 病性: 虚实夹杂 — 肝郁(实) + 脾虚(虚)
- 病机: 肝失疏泄, 横逆犯脾; 脾失健运, 湿浊内生
- 证型: **肝郁脾虚证**

**治则**: 疏肝健脾, 理气和胃

**方药**: **柴胡疏肝散合四君子汤加减**

```
君药: 柴胡 10g — 疏肝解郁, 升举阳气
臣药: 白芍 15g — 养血柔肝, 缓急止痛
     白术 12g — 健脾益气, 燥湿利水
佐药: 陈皮 6g  — 理气和中
     茯苓 15g — 健脾渗湿
     川芎 6g  — 活血行气, 止痛
     枳壳 6g  — 行气宽中除胀
使药: 甘草 6g  — 调和诸药
     生姜 3片 — 和胃止呕
     大枣 3枚 — 补中益气
```

**煎服法**: 7剂, 日1剂, 水煎分2次温服。忌生冷油腻。

**转归**: 服药3剂后胀减, 7剂后痛大缓。

## 医案二: 阴虚火旺型失眠 (张锡纯风格)

**患者**: 男, 48岁
**主诉**: 失眠多梦3个月, 加重2周

**症状详情**:
- 入睡困难, 多梦易醒
- 五心烦热, 尤以夜间为甚
- 盗汗, 醒后身凉
- 口干咽燥, 不欲多饮
- 腰膝酸软
- 舌红少苔, 脉细数

**辨证分析**:
- 病位: 心(藏神) + 肾(藏精)
- 病性: 本虚标实 — 肾阴亏虚(本) + 虚火上炎(标)
- 病机: 肾水不能上济心火, 心肾不交
- 证型: **心肾不交证 (阴虚火旺)**

**治则**: 滋阴降火, 交通心肾

**方药**: **黄连阿胶汤合天王补心丹加减**

```
君药: 黄连 5g  — 清心泻火
     阿胶 9g   — 滋阴养血 (烊化)
臣药: 生地黄 15g — 滋阴清热
     麦冬 12g — 养阴清心
佐药: 白芍 12g — 敛阴和营
     鸡子黄 2枚 — 滋阴安神 (冲入)
     酸枣仁 15g — 养心安神
     远志 6g  — 宁心安神
使药: 甘草 3g  — 调和诸药
```

**煎服法**: 5剂, 先煮黄连、生地等, 去滓, 纳阿胶烊化, 再入鸡子黄搅匀温服。睡前1小时服效佳。
**注意**: 忌辛辣刺激之物, 保持情绪平稳。

## 医案三: 痰湿蕴肺型咳嗽 (刘渡舟风格)

**患者**: 男, 55岁
**主诉**: 反复咳嗽咳痰2年, 近1周加重

**症状详情**:
- 咳嗽痰多, 色白易咯
- 胸闷脘痞
- 纳少便溏
- 体胖, 困倦乏力
- 舌体胖大有齿痕, 苔白腻, 脉濡滑

**辨证分析**:
- 病位: 肺(主气司呼吸) + 脾(主运化)
- 病性: 本虚标实 — 脾虚(本) + 痰湿蕴肺(标)
- 病机: "脾为生痰之源, 肺为贮痰之器" — 脾虚生湿, 聚湿成痰, 上渍于肺
- 证型: **痰湿蕴肺证**

**治则**: 燥湿化痰, 理气止咳

**方药**: **二陈汤合三子养亲汤加减**

```
君药: 半夏 9g  — 燥湿化痰, 降逆止呕
     陈皮 9g  — 理气化痰 (气顺则痰消)
臣药: 茯苓 12g — 健脾渗湿 (杜生痰之源)
     苏子 9g  — 降气消痰
佐药: 白芥子 6g — 温肺利气, 豁痰
     莱菔子 9g — 消食导滞, 降气祛痰
     白术 10g — 健脾益气
使药: 甘草 6g  — 调和诸药
     生姜 3片 — 制半夏之毒, 助化饮
```

**煎服法**: 7剂, 日1剂, 分2次温服。饮食宜清淡, 忌肥甘厚味。

## 医案四: 气血两虚型眩晕 (傅青主风格)

**患者**: 女, 42岁
**主诉**: 头晕乏力1年, 加重伴心悸1月

**症状详情**:
- 头晕目眩, 动则加重
- 面色萎黄无华
- 心悸失眠, 多梦易醒
- 神疲懒言
- 月经量少色淡, 周期延后
- 舌淡苔白, 脉细弱

**辨证分析**:
- 病位: 心 + 脾 + 肝
- 病性: 虚证
- 病机: 思虑过度, 劳伤心脾; 脾虚气血生化乏源, 血虚不能上荣清窍
- 证型: **气血两虚证 (心脾两虚)**

**治则**: 补益气血, 健脾养心

**方药**: **归脾汤加减**

```
君药: 黄芪 20g — 补气升阳
     当归 10g — 补血活血
臣药: 党参 15g — 补中益气
     白术 12g — 健脾益气
     龙眼肉 10g — 补益心脾, 养血安神
佐药: 茯神 15g — 宁心安神
     酸枣仁 15g — 养心安神
     远志 6g  — 宁心开窍
     木香 6g  — 理气醒脾 (防滋腻碍胃)
使药: 甘草 6g  — 调和诸药
     生姜 3片, 大枣 3枚
```

**煎服法**: 10剂, 日1剂, 分2次早晚空腹温服。宜静养, 避免劳累。
