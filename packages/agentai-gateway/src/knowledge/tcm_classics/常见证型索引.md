# 常见中医证型索引

## 八纲辨证常见证型组合

### 表证
- **风寒表证**: 恶寒发热, 头身疼痛, 无汗, 脉浮紧 → 麻黄汤
- **风热表证**: 发热微恶风, 头痛咽痛, 口渴, 脉浮数 → 银翘散
- **表虚证**: 汗出恶风, 脉浮缓 → 桂枝汤

### 里证 — 寒证
- **里实寒证 (寒邪直中)**: 腹痛腹泻, 四肢厥冷, 苔白滑, 脉沉迟 → 理中丸
- **里虚寒证 (脾胃阳虚)**: 腹痛喜温喜按, 畏寒肢冷, 便溏, 舌淡胖 → 附子理中丸

### 里证 — 热证
- **里实热证 (阳明腑实)**: 高热汗出, 大便秘结, 腹满硬痛, 舌红苔黄燥 → 大承气汤
- **里虚热证 (阴虚内热)**: 五心烦热, 盗汗颧红, 舌红少苔, 脉细数 → 知柏地黄丸

### 脏腑辨证常见证型

#### 心系
- **心血虚证**: 心悸失眠, 面色萎黄, 唇甲色淡, 舌淡脉细 → 归脾汤加减
- **心火亢盛证**: 心烦失眠, 口舌生疮, 尿赤涩痛, 舌红脉数 → 导赤散
- **心脉痹阻证**: 心胸刺痛, 固定不移, 舌暗瘀斑 → 血府逐瘀汤

#### 肝系
- **肝郁气滞证**: 胁肋胀痛, 情志抑郁, 善太息, 脉弦 → 柴胡疏肝散
- **肝火上炎证**: 头晕胀痛, 面红目赤, 口苦急躁, 脉弦数 → 龙胆泻肝汤
- **肝阳上亢证**: 眩晕耳鸣, 头胀肢麻, 腰膝酸软 → 天麻钩藤饮
- **肝胆湿热证**: 胁痛口苦, 纳呆呕恶, 身目发黄, 苔黄腻 → 茵陈蒿汤

#### 脾系
- **脾气虚证**: 纳少腹胀, 食后尤甚, 乏力懒言, 舌淡胖有齿痕 → 四君子汤
- **脾阳虚证**: 腹冷痛喜温喜按, 畏寒肢冷, 大便溏薄 → 小建中汤
- **湿热蕴脾证**: 脘腹胀闷, 不思饮食, 口苦黏腻, 苔黄腻 → 连朴饮
- **寒湿困脾证**: 脘腹痞闷, 口淡不渴, 泛恶欲呕, 苔白厚腻 → 胃苓汤

#### 肺系
- **风寒束肺证**: 咳嗽痰稀白, 鼻塞流清涕, 恶寒发热 → 止嗽散
- **风热犯肺证**: 咳嗽痰黄稠, 咽痛口渴, 发热头痛 → 桑菊饮
- **痰热壅肺证**: 咳喘胸闷, 痰多黄稠, 发热口渴 → 清金化痰汤
- **肺阴虚证**: 干咳少痰, 或痰中带血, 口燥咽干 → 百合固金汤

#### 肾系
- **肾阴虚证**: 腰膝酸软, 头晕耳鸣, 男子遗精, 女子经少 → 六味地黄丸
- **肾阳虚证**: 腰膝冷痛, 畏寒肢冷, 阳痿宫冷, 五更泄泻 → 右归丸
- **肾不纳气证**: 久病咳喘, 呼多吸少, 动则益甚 → 人参蛤蚧散
- **肾气不固证**: 小便频数清长, 或遗尿滑泄, 腰膝酸软 → 缩泉丸

#### 胃系
- **胃阴虚证**: 胃脘隐饥而不欲食, 口燥咽干, 大便干结 → 一贯煎
- **胃火炽盛证**: 胃脘灼痛, 消谷善饥, 口臭牙龈肿痛 → 清胃散
- **寒滞胃脘证**: 胃脘冷痛, 得温痛减, 遇寒加重 → 良附丸

## 气血津液辨证常见证型

| 证型 | 核心症状 | 代表方剂 |
|------|---------|---------|
| 气虚证 | 乏力气短自汗, 舌淡脉弱 | 四君子汤 |
| 气滞证 | 胀满疼痛, 窜痛, 情志波动加重 | 柴胡疏肝散 |
| 气逆证 | 咳嗽喘促, 呃逆嗳气, 头痛眩晕 | 苏子降气汤 |
| 血虚证 | 面色萎黄, 心悸失眠, 唇甲色淡 | 四物汤 |
| 血瘀证 | 刺痛固定, 舌暗瘀斑, 脉涩 | 血府逐瘀汤 |
| 血热证: 咯血尿血, 月经量多, 舌红绛 | 犀角地黄汤 |
| 痰湿证 | 体胖胸闷, 痰多易咯, 苔腻脉滑 | 二陈汤 |
| 津亏证: 口渴咽干, 皮肤干燥, 尿少便干 | 增液汤 |
